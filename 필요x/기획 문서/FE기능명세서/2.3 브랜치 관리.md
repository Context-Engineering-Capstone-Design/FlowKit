## 2.3 브랜치 관리

> 2026-08-20부터 이 화면의 이름은 `대화 노드`다. 기존 FE-BRANCH 항목은 이전 화면 호환 기록이다.

### FE-NODE-001 · 대화 구조 트리

좌측 `대화 구조`는 현재 루트와 모든 하위 노드를 한 트리로 표시한다. 별도 브랜치 목록은 표시하지 않는다. 항목을 클릭하면 해당 노드를 탭으로 연다.

### FE-NODE-002 · 응답 하단 분기

완료된 AI 응답 하단의 분기 아이콘은 모달 없이 해당 메시지까지의 고정 스냅샷을 가진 `분기 N` 노드를 만든다. 생성된 노드는 현재 노드의 부모 아래에 표시하고 즉시 연다.

### FE-BRANCH-001 · 브랜치 목록 표시

현재 대화에 만들어진 Main 브랜치와 하위 브랜치를 사이드바에 표시한다.

**화면**
사이드바 '현재 대화 — 브랜치' 영역

**관련 요구사항**
REQ-007

**관련 BE 기능**
BE-BRANCH-001

**트리거**
채팅 열기, 브랜치 생성 완료

**화면 동작**
브랜치 목록을 조회해 Main을 맨 위에 두고 생성 순서대로 나열한다. 각 항목은 색상 점과 브랜치 이름으로 구분하고, 현재 보고 있는 브랜치를 활성 상태로 강조한다.

**표시 데이터**
브랜치 이름, 브랜치 구분 색상 점, 현재 브랜치 활성 표시

**입력 검증**
없음

**오류 처리**
조회 실패 시 목록 영역에 다시 시도 안내를 표시한다.

**우선순위**
상

**비고**
브랜치가 Main 하나뿐이어도 목록 영역은 표시한다.

---

### FE-BRANCH-002 · 브랜치 전환

브랜치 항목을 클릭해 다른 대화 흐름으로 이동한다.

**화면**
사이드바 브랜치 항목, 중앙 채팅 영역

**관련 요구사항**
REQ-008, REQ-013

**관련 BE 기능**
BE-BRANCH-002

**트리거**
브랜치 항목 클릭

**화면 동작**
선택한 브랜치의 메시지 목록과 출발 Context 정보를 조회해 중앙 영역을 해당 브랜치 내용으로 교체하고, 사이드바 활성 표시를 옮긴다. 이전 브랜치에서 선택했던 블록, 편집 중이던 상태, 적용 중이던 Context는 모두 해제하고 메시지 영역을 맨 위로 올린다.

**표시 데이터**
브랜치 메시지 블록 목록, 현재 브랜치 이름

**입력 검증**
없음

**오류 처리**
조회 실패 시 오류 배너를 표시하고 이전 브랜치 화면을 유지한다.

**우선순위**
상

**비고**
편집 중인 내용이 있으면 사용자에게 확인 후 전환한다.

---

### FE-BRANCH-003 · 현재 브랜치 표시

Main이 아닌 브랜치를 보고 있을 때 상단에 현재 브랜치를 알려준다.

**화면**
중앙 채팅 영역 상단 브랜치 배너

**관련 요구사항**
REQ-011

**관련 BE 기능**
BE-BRANCH-002

**트리거**
브랜치 전환, 브랜치 화면 진입

**화면 동작**
하위 브랜치를 보고 있으면 상단에 '현재 브랜치: (이름)' 배너를 표시하고, Main 브랜치에서는 배너를 감춘다.

**표시 데이터**
브랜치 아이콘, 현재 브랜치 이름

**입력 검증**
없음

**오류 처리**
브랜치 이름이 없으면 배너를 표시하지 않는다.

**우선순위**
중

---

### FE-BRANCH-004 · 출발 Context 요약 표시

브랜치에 진입하면 그 브랜치가 어떤 Context에서 출발했는지 상단에 보여준다.

**화면**
중앙 채팅 영역 상단 Context 요약 블록

**관련 요구사항**
REQ-011

**관련 BE 기능**
BE-BRANCH-002, BE-BRANCH-005

**트리거**
하위 브랜치 진입

**화면 동작**
메시지 목록 맨 위에 'Context 요약' 배지가 붙은 블록을 표시하고, 브랜치 출발에 사용된 Context 블록들을 역할(User·AI) 구분과 미리보기 텍스트를 담은 pill 형태로 나열한다.

**표시 데이터**
Context 요약 배지, 요약 문구, 출발 Context 블록 pill 목록

**입력 검증**
없음

**오류 처리**
출발 Context 정보가 없으면 요약 블록 전체를 표시하지 않는다.

**우선순위**
중

**비고**
요약 내용은 서버가 저장한 원본 Context 참조를 표시하는 것이며 화면에서 새로 요약하지 않는다.

---

### FE-BRANCH-005 · 원본 Context 위치 이동

Context 요약의 pill을 클릭해 원본 메시지 블록 위치로 이동한다.

**화면**
Context 요약 pill, 중앙 채팅 영역

**관련 요구사항**
REQ-012

**관련 BE 기능**
BE-BRANCH-002

**트리거**
Context 요약 pill 클릭

**화면 동작**
pill이 가리키는 원본 블록이 현재 브랜치에 있으면 해당 위치로 부드럽게 스크롤하고 잠시 강조 표시한다. 원본이 다른 브랜치에 있으면 그 브랜치로 먼저 이동한 뒤 같은 방식으로 위치를 강조한다.

**표시 데이터**
원본 블록 강조 효과

**입력 검증**
없음

**오류 처리**
원본 블록을 찾지 못하면 이동하지 않고 안내 문구를 표시한다.

**우선순위**
중

---

### FE-BRANCH-006 · 브랜치 생성 모달

브랜치 생성 버튼을 눌러 이름·분기 지점·포함 Context를 설정하는 모달을 연다.

**화면**
브랜치 생성 모달

**관련 요구사항**
REQ-009

**관련 BE 기능**
BE-BRANCH-003

**트리거**
브랜치 생성 버튼 클릭, Context 패널의 '이 Context로 브랜치 생성' 클릭

**화면 동작**
모달을 열어 브랜치 이름 입력창, 추천 이름 버튼, 분기 지점 선택 목록, 포함할 Context 블록 선택 목록을 표시한다. 분기 지점은 현재 브랜치의 메시지 블록으로 채우고 현재 보고 있는 위치를 기본 선택한다. Context 블록 목록은 현재 대화의 블록으로 채우되, 이미 선택된 블록은 체크된 상태로 표시한다.

**표시 데이터**
브랜치 이름 입력값, 추천 이름 버튼, 분기 지점 목록, Context 블록 체크 목록

**입력 검증**
없음(생성 시점에 검증)

**오류 처리**
분기 지점이나 블록 목록을 불러오지 못하면 해당 영역에 안내를 표시한다.

**우선순위**
상

**비고**
추천 이름 버튼을 누르면 이름 입력창에 문구가 채워지고 사용자가 이어서 수정할 수 있다.

---

### FE-BRANCH-007 · 브랜치 생성 실행

모달에서 설정한 내용으로 새 브랜치를 만든다.

**화면**
브랜치 생성 모달, 사이드바 브랜치 목록

**관련 요구사항**
REQ-010

**관련 BE 기능**
BE-BRANCH-003, BE-BRANCH-004, BE-BRANCH-005

**트리거**
모달의 '브랜치 생성' 버튼 클릭

**화면 동작**
브랜치 이름, 기준 브랜치, 분기 지점, 선택한 Context 블록을 서버로 전달해 생성을 요청한다. 생성에 성공하면 모달을 닫고 사이드바 브랜치 목록을 갱신한 뒤, 만든 브랜치로 바로 이동한다.

**표시 데이터**
새 브랜치 항목(색상 점, 이름), 이동한 브랜치 화면

**입력 검증**
브랜치 이름 빈 값 확인, 분기 지점 선택 여부 확인

**오류 처리**
이름 중복·분기 지점 없음·Context 블록 없음 등 서버 오류를 모달 내 안내 영역에 표시하고 입력값은 유지한다. 생성 요청 중에는 버튼을 비활성화해 중복 생성을 막는다.

**우선순위**
상

**비고**
브랜치를 만들어도 원본 대화는 그대로 유지된다. 목록만 갱신하고 머무르면 방금 만든 브랜치를 다시 찾아 들어가야 하므로 바로 이동한다.

---

### FE-BRANCH-008 · 분기 지점 이후 블록 선택 제한

분기 지점보다 뒤에 있는 블록은 Context로 고를 수 없게 한다.

**화면**
브랜치 생성 모달의 Context 블록 목록

**관련 요구사항**
REQ-009, REQ-010

**관련 BE 기능**
BE-BRANCH-003

**트리거**
분기 지점 변경

**화면 동작**
Context 블록 목록에 분기 지점까지의 블록만 표시한다. 분기 지점을 앞쪽으로 바꿔서 이미 고른 블록이 범위를 벗어나면, 생성 시점에 그 블록을 제외하고 요청한다.

**표시 데이터**
선택 가능한 블록 목록, 선택 개수

**입력 검증**
선택한 블록이 분기 지점 범위 안에 있는지 확인

**오류 처리**
없음

**우선순위**
중

**비고**
분기 지점 이후 블록은 새 브랜치에 존재하지 않으므로 출발 Context가 될 수 없다.
> 2026-08-20 변경: 브랜치 생성 모달의 Context 블록 체크 목록과 메시지별 분기 진입은 제거한다. 헤더의 일반 브랜치 생성만 남기며, Context 블록은 전달하지 않는다.
