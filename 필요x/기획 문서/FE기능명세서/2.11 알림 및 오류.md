## 2.11 알림 및 오류

서버는 표준 형식의 오류·성공 정보를 내려주고, 어떤 방식으로 보여줄지는 화면이 정한다. 작업 실패처럼 사용자가 알아야 하고 조치가 필요한 상황은 오류 배너로, 저장·복사·전환처럼 결과만 알리면 되는 상황은 토스트로 표시한다.

### FE-NOTIFY-001 · 오류 배너 표시

주요 오류 상황을 화면 상단 배너로 알린다.

**화면**
중앙 채팅 영역 상단 오류 배너

**관련 요구사항**
REQ-064

**관련 BE 기능**
BE-NOTIFY-001, BE-NOTIFY-002

**트리거**
서버 오류 응답 수신, 화면에서 감지한 처리 실패

**화면 동작**
배너를 열어 경고 아이콘과 오류 문구, 닫기 버튼을 표시한다. 문구는 서버가 내려준 사용자용 메시지를 쓰고, 개발용 상세 내용은 표시하지 않는다. 새 오류가 생기면 기존 배너 내용을 새 내용으로 바꾼다.

**표시 데이터**
경고 아이콘, 오류 문구, 닫기 버튼

**입력 검증**
없음

**오류 처리**
정의되지 않은 오류 코드는 공통 문구로 대체한다.

**우선순위**
중

**비고**
배너는 사용자가 닫거나 해당 문제가 해결될 때까지 유지한다.

---

### FE-NOTIFY-002 · 오류 배너 닫기

표시된 오류 배너를 닫는다.

**화면**
오류 배너 닫기 버튼

**관련 요구사항**
REQ-064

**관련 BE 기능**
없음(화면 상태)

**트리거**
닫기 버튼 클릭, 해당 오류의 원인이 해소된 동작 완료

**화면 동작**
배너를 감춘다. 원인이 해소되는 동작(예: API 키 등록 완료)이 성공하면 관련 배너를 자동으로 닫는다.

**표시 데이터**
없음

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
중

### FE-NOTIFY-003 · 토스트 알림 표시

주요 작업의 결과를 짧은 알림으로 알린다.

**화면**
화면 위에 잠깐 나타나는 토스트

**관련 요구사항**
REQ-065

**관련 BE 기능**
BE-NOTIFY-003

**트리거**
저장, 복사, 승인, 거절, 적용, 전환, 생성 등 주요 작업 완료

**화면 동작**
결과 성격에 맞는 아이콘과 문구를 담은 토스트를 띄우고 일정 시간 뒤 자동으로 없앤다. 성공, 주의, 정보 등 성격에 따라 색과 아이콘을 구분한다. 새 토스트가 뜨면 이전 토스트는 지우고 하나만 표시한다.

**표시 데이터**
상태 아이콘, 결과 문구

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
하

**비고**
표시 시간과 위치는 화면이 정한다. 사용자의 조치가 필요한 실패는 토스트가 아니라 오류 배너로 알린다.

---

### FE-NOTIFY-004 · 부분 실패 결과 표시

여러 항목을 한 번에 처리했을 때 일부만 실패한 결과를 알린다.

**화면**
오류 배너, 토스트, 해당 작업 목록

**관련 요구사항**
REQ-064, REQ-065

**관련 BE 기능**
BE-NOTIFY-004

**트리거**
전체 승인, 전체 거절, 여러 첨부 처리 등에서 일부 실패 응답 수신

**화면 동작**
성공한 항목은 화면에 정상 반영하고, 실패한 항목은 목록에 남긴다. 성공·실패 개수를 함께 알리고, 실패 사유는 오류 배너로 표시한다.

**표시 데이터**
성공·실패 개수, 실패 사유, 목록에 남은 실패 항목

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
중

**비고**
전체가 성공한 경우와 구분되게 알려서, 사용자가 남은 항목을 다시 처리할 수 있게 한다.

---

### FE-NOTIFY-005 · 처리 중 상태 표시

시간이 걸리는 작업이 진행 중임을 알린다.

**화면**
각 작업 영역(메시지 생성, 정제 미리보기, 연결 확인, 업로드 등)

**관련 요구사항**
REQ-064, REQ-065

**관련 BE 기능**
없음(화면 상태)

**트리거**
서버 요청 시작

**화면 동작**
요청이 진행되는 동안 해당 영역에 진행 표시를 보여주고, 같은 요청을 다시 보내지 못하도록 관련 버튼을 비활성화한다. 응답을 받으면 진행 표시를 결과로 바꾸고 버튼을 되돌린다.

**표시 데이터**
진행 표시, 버튼 비활성 상태

**입력 검증**
없음

**오류 처리**
응답이 지나치게 늦어지면 진행 표시를 멈추고 다시 시도할 수 있게 안내한다.

**우선순위**
중
