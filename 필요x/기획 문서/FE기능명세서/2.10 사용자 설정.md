## 2.10 사용자 설정

프로필 메뉴 표시와 사용자 정보 수정 화면은 2.1 인증 및 계정에서 다룬다(FE-AUTH-004, FE-AUTH-005). 이 문서는 API 키 관리와 피드백을 다룬다.

### FE-USERSET-001 · API 키 관리 모달

프로필 메뉴의 'API 키 관리'를 눌러 등록 상태를 확인하고 키를 다룬다.

**화면**
API 키 관리 모달

**관련 요구사항**
REQ-060

**관련 BE 기능**
BE-USERSET-001

**트리거**
프로필 메뉴의 'API 키 관리' 클릭

**화면 동작**
모달을 열고 맨 위에 등록 상태 배지를 표시한다. 등록되어 있으면 'API 키 등록됨', 없으면 'API 키 미등록'으로 구분해 보여준다. 아래에는 API 키 입력창을 가림 상태로 두고, 등록된 키가 있으면 삭제 버튼을 함께 노출한다. 연결 확인 결과 영역은 처음엔 감춰 둔다.

**표시 데이터**
등록 상태 배지, API 키 입력창, 보기·숨기기 버튼, 저장·삭제·연결 확인 버튼

**입력 검증**
없음

**오류 처리**
상태 조회에 실패하면 미등록 상태로 표시하고 안내를 남긴다.

**우선순위**
중

**비고**
서버는 저장된 API 키 원문을 돌려주지 않는다. 화면에는 등록 여부와 끝 네 자리 같은 표시용 정보만 보여준다.

---

**관련 요구사항**
REQ-060

**관련 BE 기능**
없음(화면 상태)

**트리거**
보기·숨기기 버튼 클릭

**화면 동작**

**표시 데이터**
가림·표시 상태, 버튼 아이콘

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
중

### FE-USERSET-003 · API 키 저장

입력한 API 키를 저장한다.

**화면**
API 키 관리 모달 저장 버튼

**관련 요구사항**
REQ-060

**관련 BE 기능**
BE-USERSET-003

**트리거**
저장 버튼 클릭

**화면 동작**
입력한 키를 서버로 보내 저장을 요청한다. 성공하면 등록 상태 배지를 '등록됨'으로 바꾸고 삭제 버튼을 노출한 뒤 모달을 닫고 완료 알림을 표시한다. 저장 후에는 입력창에 키 원문을 남기지 않는다.

**표시 데이터**
갱신된 등록 상태 배지, 완료 알림

**입력 검증**
빈 값 확인, 기본 형식·길이 확인

**오류 처리**
입력이 비어 있으면 'API 키를 입력해달라'는 안내를 표시하고 요청하지 않는다. 형식 오류나 저장 실패는 모달 안에 사유를 표시하고 입력 내용은 유지한다.

**우선순위**
중

---

### FE-USERSET-004 · API 키 삭제

저장된 API 키를 지운다.

**화면**
API 키 관리 모달 삭제 버튼

**관련 요구사항**
REQ-060

**관련 BE 기능**
BE-USERSET-004

**트리거**
삭제 버튼 클릭

**화면 동작**
삭제를 서버에 요청하고, 성공하면 입력창을 비우고 등록 상태 배지를 '미등록'으로 바꾼다. 삭제 버튼과 연결 확인 결과 영역을 감추고 완료 알림을 표시한다.

**표시 데이터**
미등록 상태 배지, 완료 알림

**입력 검증**
없음

**오류 처리**
삭제 실패 시 사유를 모달 안에 표시하고 기존 등록 상태를 유지한다.

**우선순위**
중

**비고**
되돌릴 수 없는 동작이므로 삭제 전에 확인을 받는다.

---

### FE-USERSET-005 · API 연결 확인

등록한 API 키로 실제 연결이 되는지 확인한다.

**화면**
API 키 관리 모달 연결 확인 버튼, 결과 영역

**관련 요구사항**
REQ-061

**관련 BE 기능**
BE-USERSET-005

**트리거**
연결 확인 버튼 클릭

**화면 동작**
결과 영역을 열어 '연결 확인 중' 진행 표시를 보여주고 서버에 확인을 요청한다. 성공하면 '연결 성공'과 확인 시각을, 실패하면 '연결 실패'와 사유를 결과 영역에 표시한다. 각 상태는 색과 아이콘으로 구분한다.

**표시 데이터**
진행 표시, 연결 성공·실패 결과, 확인 시각 또는 실패 사유

**입력 검증**
등록된 키 존재 여부 확인

**오류 처리**
등록된 키가 없으면 요청하지 않고 'API 키를 먼저 등록해달라'는 안내를 결과 영역에 표시한다.

**우선순위**
하

### FE-USERSET-006 · API 키 미등록 안내

API 키 없이 메시지를 보내려 할 때 안내한다.

**화면**
오류 배너

**관련 요구사항**
REQ-062

**관련 BE 기능**
BE-USERSET-006

**트리거**
API 키가 필요한 모델로 메시지 전송 시도

**화면 동작**
서버가 API 키 미등록 오류를 반환하면 화면 상단 오류 배너에 등록이 필요하다는 안내를 표시한다. 안내에서 API 키 관리 화면으로 바로 갈 수 있게 한다.

**표시 데이터**
오류 배너 안내 문구, API 키 관리 이동 경로

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
중

**비고**
서비스 공용 키를 쓰는 모델에서는 이 안내가 뜨지 않는다.

---

### FE-USERSET-007 · 피드백 제출

서비스 오류나 개선 의견을 남긴다.

**화면**
피드백 남기기 모달

**관련 요구사항**
REQ-063

**관련 BE 기능**
BE-USERSET-007

**트리거**
프로필 메뉴의 '피드백 남기기' 클릭(열림), 제출 버튼 클릭(전송)

**화면 동작**
모달을 열면 유형 선택 버튼('오류', '사용성 불편', 'Context 편집 문제', '브랜치 기능 문제', '기타')과 내용 입력 영역을 비운 상태로 보여준다. 유형 버튼을 누르면 하나만 선택 상태가 된다. 제출하면 유형과 내용을 서버로 보내고, 성공하면 모달을 닫고 완료 알림을 표시한다.

**표시 데이터**
유형 선택 버튼, 선택 상태, 내용 입력 영역

**입력 검증**
유형 선택 여부 확인, 내용 빈 값·길이 확인

**오류 처리**
유형을 고르지 않았거나 내용이 비어 있으면 각각 안내를 표시하고 제출하지 않는다. 저장 실패 시 사유를 표시하고 입력 내용은 유지한다.

**우선순위**
하
