## 2.7 Context 적용

Context를 고르고 적용 상태를 표시하는 일은 화면이 담당한다. 서버는 메시지를 실제로 보내는 시점에만 검증하고 사용 이력을 남긴다.

### FE-CTXAPPLY-001 · 정제된 Context 미리보기

다음 질문에 쓸 Context를 적용하기 전에 확인한다.

**화면**
Context 패널 '블록별 정제 미리보기' 영역, '선택된 블록' 영역

**관련 요구사항**
REQ-045

**관련 BE 기능**
BE-REFINE-004

**트리거**
블록 선택, 정제 완료

**화면 동작**
적용 대상이 될 블록을 패널에서 확인할 수 있게 한다. 정제를 실행했다면 정제 결과 미리보기 영역에서 원본과 정제본을 함께 보여주고, 승인된 내용이 실제 적용 대상임을 알 수 있게 한다.

**표시 데이터**
선택된 블록 목록, 정제 결과 미리보기

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
상

**비고**
승인하지 않은 정제 결과는 적용 대상이 아니다. 적용에는 각 블록의 현재 확정 내용만 쓰인다.

---

### FE-CTXAPPLY-002 · Context 적용

선택·정제한 Context를 다음 질문에 적용한다.

**화면**
Context 패널 '이 Context로 질문하기' 버튼, 입력창 위 Context 표시

**관련 요구사항**
REQ-046

**관련 BE 기능**
없음(전송 시점에 BE-CTXAPPLY-001, BE-CTXAPPLY-002가 처리)

**트리거**
'이 Context로 질문하기' 버튼 클릭

**화면 동작**
현재 선택된 블록을 적용 대상으로 확정해 화면 상태에 보관하고, 입력창 위에 적용 중임을 알리는 표시를 띄운다. 입력창으로 포커스를 옮기고 적용 완료 알림을 보여준다.

**표시 데이터**
적용 중 표시, 적용 완료 알림

**입력 검증**
선택된 블록 1개 이상 확인

**오류 처리**
선택된 블록이 없으면 적용하지 않고 안내를 표시한다.

**우선순위**
상

**비고**
이 단계에서는 서버에 저장하지 않는다. 실제 검증과 이력 저장은 메시지를 보낼 때 이뤄진다.

---

### FE-CTXAPPLY-003 · 적용 중인 Context 표시

지금 어떤 Context가 적용 중인지 입력창 위에 보여준다.

**화면**
입력창 위 Context 표시

**관련 요구사항**
REQ-047

**관련 BE 기능**
없음(화면 상태)

**트리거**
Context 적용, 적용 대상 변경

**화면 동작**
입력창 바로 위에 Context 이름과 포함된 블록 개수를 함께 표시한다(예: '핵심 요약 Context 적용 중 · 3개 블록'). 이름은 사용자가 입력한 편집 지시를 참고해 정하고, 해당하는 문구가 없으면 기본 이름을 쓴다. 표시 오른쪽에는 해제 버튼을 둔다.

**표시 데이터**
Context 이름, 포함 블록 개수, 해제 버튼

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
상

**비고**
채팅을 바꾸거나 브랜치를 전환하거나 새 채팅을 시작하면 적용 표시를 자동으로 없앤다.

**표시 데이터**
해제 알림

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
중

### FE-CTXAPPLY-005 · 메시지 전송 시 Context 전달

메시지를 보낼 때 적용 중인 Context를 함께 전달한다.

**화면**
입력창 전송 버튼

**관련 요구사항**
REQ-046

**관련 BE 기능**
BE-CTXAPPLY-001, BE-CTXAPPLY-002, BE-CTXAPPLY-003

**트리거**
전송 버튼 클릭, 전송 단축키 입력

**화면 동작**
입력한 질문과 함께 적용 중인 Context 블록 목록을 서버로 보낸다. 서버가 검증과 Context 확정을 마치고 응답을 생성하면 그 결과를 화면에 표시한다. 전송이 끝나면 적용 상태와 블록 선택을 함께 해제한다.

**표시 데이터**
전송한 질문 블록, 생성 중 표시, AI 응답 블록

**입력 검증**
질문 내용 빈 값 확인

**오류 처리**
전달한 Context 대상이 더 이상 유효하지 않다는 응답을 받으면 오류 배너로 알리고 적용 표시를 해제한다. 전송이 실패하면 현재 대화를 다시 불러와 화면을 서버 상태에 맞춘다.

**우선순위**
상

**비고**
승인되어 블록의 현재 내용이 된 정제본만 Context로 쓰인다. 대기·거절 상태의 정제 결과는 전달되지 않는다. 한 번 쓴 Context를 남겨두면 다음 질문까지 같은 맥락에 묶여 의도하지 않은 답이 나오므로, 전송 후 자동으로 해제한다.
