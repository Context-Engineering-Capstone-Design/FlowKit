## 2.4 메시지 블록 관리

### BE-MSG-001 · 메시지 블록 생성

사용자 프롬프트 또는 AI 응답을 현재 브랜치에 속한 메시지 블록으로 저장한다.

**도메인**
MessageBlock

**관련 요구사항**
REQ-013

**관련 화면**
메시지 전송, AI 응답 표시

**입력**
userId, chatId, branchId, role, content, sourceType

**처리**
채팅·브랜치 접근 권한을 확인하고 role, content를 검증한 뒤 Branch 내 표시 순서를 부여해 MessageBlock을 생성한다.

**출력**
messageBlockId, role, content, orderIndex, createdAt

**DB 영향**
MessageBlock 생성, MessageBlockVersion 생성

**상태 변화**
없음 → 메시지 블록 생성

**권한**
로그인 필요, 채팅 소유자

**오류**
브랜치 없음, 내용 없음, 권한 없음, 생성 실패

**우선순위**
상

**비고**
AI 응답 내용 생성 자체는 AI 모델링/AI 응답 관리 파트 책임

---

### BE-MSG-002 · 브랜치 메시지 블록 목록 조회

선택한 브랜치에 속한 메시지 블록 목록을 화면 표시 순서대로 조회한다.

**도메인**
MessageBlock

**관련 요구사항**
REQ-013

**관련 화면**
중앙 채팅 영역, 브랜치 전환

**입력**
userId, chatId, branchId

**처리**
채팅·브랜치 접근 권한을 확인하고 해당 Branch의 MessageBlock을 orderIndex 기준으로 조회하되, 각 블록은 currentVersionId 기준의 본문을 반환한다.

**출력**
messageBlocks(blockId, role, content, currentVersionId, sourceType, orderIndex, createdAt)

**DB 영향**
MessageBlock 조회, MessageBlockVersion 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
브랜치 없음, 메시지 없음, 권한 없음

**우선순위**
상

**비고**
BE-CHAT-005, BE-BRANCH-002 내부 재사용 가능. 별도 외부 API 노출 불필요

---

### BE-MSG-003 · 메시지 블록 선택 대상 검증

정제, Context 적용, 브랜치 생성 등 실행 요청 시점에 선택된 메시지 블록이 현재 채팅·브랜치에서 유효한지 검증한다.

**도메인**
MessageBlock

**관련 요구사항**
REQ-014, REQ-015, REQ-016, REQ-023

**관련 화면**
메시지 블록 선택, 정제·적용·브랜치 생성 실행

**입력**
userId, chatId, branchId, selectedBlockIds

**처리**
선택된 blockId 목록이 해당 Branch에 속하는지, 삭제되거나 접근 불가한 블록이 아닌지 확인한다.

**출력**
validBlockIds, invalidBlockIds, selectedCount

**DB 영향**
MessageBlock 조회

**상태 변화**
선택 후보 검증

**권한**
로그인 필요, 채팅 소유자

**오류**
블록 없음, 브랜치 불일치, 권한 없음

**우선순위**
상

**비고**
선택 표시·선택 수·패널 렌더링은 FE 상태 사용. BE 검증은 실행 요청 시점에만 수행

---

### BE-MSG-004 · 메시지 블록 수정본 저장 및 활성화

사용자가 수정한 메시지 블록 내용을 새 버전으로 저장하고 해당 블록의 현재 활성 버전으로 설정한다.

**도메인**
MessageBlock, Version

**관련 요구사항**
REQ-018, REQ-020, REQ-021

**관련 화면**
메시지 블록 수정 모드

**입력**
userId, chatId, branchId, blockId, editedContent

**처리**
기존 원본 버전은 유지한 채 editedContent를 새 MessageBlockVersion으로 저장하고, MessageBlock.currentVersionId를 새 버전으로 변경한다.

**출력**
blockId, currentVersionId, editedContent, versionNo

**DB 영향**
MessageBlock 수정, MessageBlockVersion 생성

**상태 변화**
원본 버전 유지 → 수정본 활성화

**권한**
로그인 필요, 채팅 소유자

**오류**
블록 없음, 내용 없음, 권한 없음, 버전 저장 실패

**우선순위**
상

**비고**
새 브랜치를 생성하지 않고 같은 브랜치 내 활성 버전만 변경한다. 이후 AI 응답 생성 시 현재 활성 버전을 Context로 사용

---

### BE-MSG-005 · 메시지 블록 버전 목록 조회

하나의 메시지 블록에 저장된 버전 목록을 조회한다.

**도메인**
MessageBlock, Version

**관련 요구사항**
REQ-020, REQ-021, REQ-034

**관련 화면**
메시지 블록 버전 이동 버튼, 버전 복구 버튼

**입력**
userId, chatId, branchId, blockId

**처리**
메시지 블록 접근 권한을 확인하고 해당 blockId의 버전 목록을 versionNo 기준으로 조회한다.

**출력**
versions(versionId, versionNo, content, sourceType, createdAt, isCurrent)

**DB 영향**
MessageBlockVersion 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
블록 없음, 버전 없음, 권한 없음

**우선순위**
중

**비고**
정제 승인 후 이전 내용 확인에 사용

---

### BE-MSG-006 · 메시지 블록 활성 버전 변경

사용자가 선택한 특정 버전을 해당 메시지 블록의 현재 활성 버전으로 변경한다.

**도메인**
MessageBlock, Version

**관련 요구사항**
REQ-020, REQ-021, REQ-034

**관련 화면**
이전/다음 버전 이동 버튼, 버전 복구 버튼

**입력**
userId, chatId, branchId, blockId, targetVersionId

**처리**
targetVersionId가 해당 blockId에 속하는 유효한 버전인지 확인한 뒤 MessageBlock.currentVersionId를 targetVersionId로 변경한다.

**출력**
blockId, currentVersionId, content, versionNo

**DB 영향**
MessageBlock 수정, MessageBlockVersion 조회

**상태 변화**
현재 활성 버전 → 선택 버전 활성화

**권한**
로그인 필요, 채팅 소유자

**오류**
대상 버전 없음, 블록 없음, 권한 없음, 버전 변경 실패

**우선순위**
중

**비고**
버전 이력 유지

---

REQ-013, REQ-018, REQ-020

AI 응답 생성, Context 적용

**입력**
userId, chatId, branchId

**처리**
브랜치 접근 권한을 확인하고 orderIndex 순서대로 MessageBlock을 조회하되, 각 블록의 currentVersionId에 해당하는 content만 구성한다.

**출력**
activeMessageFlow(blockId, role, content, versionId, orderIndex)

**DB 영향**
MessageBlock 조회, MessageBlockVersion 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
브랜치 없음, 메시지 없음, 권한 없음

**우선순위**
상

**비고**
AI 응답 생성·Context 적용 등 실행 시점에 서버 기준 currentVersionId로 구성

### BE-MSG-008 · 메시지 블록 접근 권한 검증

사용자가 특정 메시지 블록에 접근하거나 수정할 수 있는지 공통으로 검증한다.

**도메인**
MessageBlockAuth

**관련 요구사항**
REQ-013, REQ-014, REQ-018, REQ-020, REQ-021

**관련 화면**
메시지 블록 관련 전체 기능

**입력**
userId, chatId, branchId, blockId

**처리**
MessageBlock이 해당 Branch와 Chat에 속하는지 확인하고 Chat ownerId와 요청 userId를 비교한다.

**출력**
hasAccess 또는 권한 오류

**DB 영향**
Chat 조회, Branch 조회, MessageBlock 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
MESSAGE_BLOCK_NOT_FOUND, BRANCH_NOT_FOUND, CHAT_ACCESS_DENIED

**우선순위**
상

**비고**
공통 서비스 함수로 구현 권장
