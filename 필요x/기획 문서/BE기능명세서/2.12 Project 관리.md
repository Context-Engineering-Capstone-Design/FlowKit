## 2.12 Project 관리

### BE-PROJECT-001 · Project와 소속 대화 관리

사용자는 Project를 만들고 이름·전용 지침을 수정하거나 삭제할 수 있다. 대화는 하나의 Project에만 속하며, 메인 대화를 이동하면 그 사이드 채팅 트리도 같은 Project로 이동한다. Project 삭제 시 소속 대화·메모리·연결 Library 자료를 함께 삭제한다.

### BE-PROJECT-002 · 전용 메모리와 Library 자료

Project 설정에서 본문형 메모리와 Library 자료를 관리한다. 메모리는 해당 Project의 모든 대화 입력에 자동 반영한다. Library 자료는 후보로만 보관하고, 사용자가 전송 때 선택한 자료만 AI 입력 스냅샷과 사용 이력에 저장한다.

### BE-PROJECT-003 · AI 입력 우선순위

일반 지침보다 Project 지침을 먼저 적용한다. 개별 Context는 Project 지침보다 우선하며, 현재 사용자의 명시적 요청이 최우선이다. Project 밖 대화와 다른 Project에는 전용 지침·메모리를 전달하지 않는다.
