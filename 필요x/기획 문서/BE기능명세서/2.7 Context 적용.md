## 2.7 Context 적용

**FE/BE 책임 기준:** 전송 전 Context pill 표시·선택은 FE 상태. BE는 전송 시점 검증·snapshot 확정·사용 이력(AppliedContextLog) 저장만 담당. 최종 AI 입력 구성은 2.8 BE-AIRESP-001 책임.

### BE-CTXAPPLY-001 · 메시지 전송 시 적용 Context 검증

사용자가 Context를 적용한 상태로 메시지를 전송할 때, 전달된 Context 대상이 현재 채팅·브랜치에서 유효한지 검증한다.

**도메인**
ContextApply, MessageBlock

**관련 요구사항**
REQ-046

**관련 화면**
이 Context로 질문하기 버튼, 메시지 전송

**입력**
userId, chatId, branchId, userPrompt, contextBlockIds 또는 contextVersionIds

**처리**
전달된 blockId 또는 versionId가 해당 Branch에 속하는지, 접근 가능한지, 삭제되지 않았는지 검증한다.

**출력**
validationResult, validContextTargets

**DB 영향**
MessageBlock 조회, MessageBlockVersion 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
Context 대상 없음, 블록 없음, 버전 없음, 브랜치 불일치, 권한 없음

**우선순위**
상

**비고**
Context pill 표시·해제·미리보기는 FE 상태

---

### BE-CTXAPPLY-002 · 적용 Context 스냅샷 구성

AI 응답 생성에 사용할 적용 Context를 서버 기준으로 확정한다.

**도메인**
ContextApply, MessageBlock, Version

**관련 요구사항**
REQ-046

**관련 화면**
메시지 전송

**입력**
userId, chatId, branchId, validContextTargets

**처리**
각 blockId의 currentVersionId 또는 전달된 유효 versionId 기준으로 content를 조회하고, BE-AIRESP-001에 전달할 Context snapshot을 구성한다.

**출력**
appliedContextSnapshot(contextItems, sourceBlockIds, versionIds)

**DB 영향**
MessageBlock 조회, MessageBlockVersion 조회

**상태 변화**
적용 Context 기준 데이터 확정

**권한**
로그인 필요, 채팅 소유자

**오류**
본문 없음, 버전 불일치, 조회 실패

**우선순위**
상

**비고**
pending/rejected 정제 결과는 사용하지 않음. 승인되어 currentVersionId가 된 내용만 반영

---

### BE-CTXAPPLY-003 · 적용 Context 사용 이력 저장

어떤 Context가 특정 사용자 메시지 또는 AI 응답 생성에 사용되었는지 추적할 수 있도록 사용 이력을 저장한다.

**도메인**
ContextApply

**관련 요구사항**
REQ-047

**관련 화면**
AI 응답 결과, 적용 Context 표시

**입력**
userMessageId 또는 aiResponseId, appliedContextSnapshot

**처리**
메시지 전송 또는 AI 응답 생성 요청과 연결해 적용 Context snapshot을 AppliedContextLog로 저장한다.

**출력**
appliedContextLogId, contextItems

**DB 영향**
AppliedContextLog 생성, AppliedContextItem 생성

**상태 변화**
Context 사용 이력 저장

**권한**
로그인 필요, 채팅 소유자

**오류**
메시지 없음, Context 없음, 저장 실패

**우선순위**
중

**비고**
전송 전 Context pill 상태는 서버에 저장하지 않음. 전송 후 사용 이력만 저장

---

### BE-CTXAPPLY-004 · Context 적용 접근 권한 검증

사용자가 해당 채팅·브랜치에서 Context를 적용해 메시지를 전송할 수 있는지 공통으로 검증한다.

**도메인**
ContextApplyAuth

**관련 요구사항**
REQ-046, REQ-047

**관련 화면**
Context 적용 관련 실행 기능

**입력**
userId, chatId, branchId, contextBlockIds 또는 contextVersionIds

**처리**
Chat ownerId와 요청 userId를 비교하고, branchId 및 Context 대상이 해당 Chat에 속하는지 확인한다.

**출력**
hasAccess 또는 권한 오류

**DB 영향**
Chat 조회, Branch 조회, MessageBlock 조회 가능

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
CHAT_NOT_FOUND, BRANCH_NOT_FOUND, CONTEXT_TARGET_NOT_FOUND, ACCESS_DENIED

**우선순위**
상

**비고**
공통 서비스 함수로 구현 권장
