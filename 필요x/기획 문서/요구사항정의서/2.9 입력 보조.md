## 2.9 입력 보조 요구사항

### REQ-052 · 파일 첨부

사용자는 채팅 입력창에서 일반 파일을 첨부할 수 있어야 한다.

**입력**
파일 업로드 선택

**결과**
파일 chip 표시

**수용 기준**
파일 선택 후 입력창 영역에 파일명과 확장자가 표시되어야 한다.

**우선순위**
하

---

### REQ-053 · 이미지 첨부

사용자는 채팅 입력창에서 이미지를 첨부할 수 있어야 한다.

**입력**
사진 업로드 선택

**결과**
이미지 chip 표시

**수용 기준**
이미지 선택 후 입력창 영역에 이미지 첨부 상태가 표시되어야 한다.

**우선순위**
하

---

### REQ-054 · 첨부 항목 제거

사용자는 첨부한 파일 또는 이미지를 제거할 수 있어야 한다.

**입력**
첨부 chip의 제거 버튼 클릭

**결과**
첨부 항목 삭제

**수용 기준**
제거 버튼 클릭 시 해당 첨부 chip이 입력창에서 사라져야 한다.

**우선순위**
하

---

### REQ-055 · 웹 검색 토글

사용자는 입력창 하단에서 웹 검색 사용 여부를 전환할 수 있어야 한다.

**입력**
웹 검색 버튼 클릭

**결과**
활성/비활성 상태 변경

**수용 기준**
버튼 클릭 시 웹 검색 버튼의 활성 상태가 시각적으로 변경되어야 한다.

**우선순위**
하

---

### REQ-056 · 모델 선택

사용자는 입력창 하단에서 사용할 AI 모델을 선택할 수 있어야 한다.

**입력**
모델 선택 버튼 클릭

**결과**
모델 드롭다운 표시

**수용 기준**
선택 가능한 모델 목록이 표시되고 선택한 모델명이 버튼에 반영되어야 한다.

**우선순위**
하

---

**입력**
-

**결과**
-

**수용 기준**
MVP: 마이크 버튼 UI, 서버 STT, 음성 파일 업로드, 음성 텍스트 변환 미구현. 후순위: 입력창 하단 마이크 버튼 표시 및 음성 입력 지원

**우선순위**
하

---

### REQ-068 · 붙여넣기·끌어다 놓기로 파일 첨부

사용자는 파일 선택 창을 거치지 않고 붙여넣기나 끌어다 놓기로도 파일을 첨부할 수 있어야 한다.

**입력**
이미지 붙여넣기 또는 파일 끌어다 놓기

**결과**
첨부 목록에 항목 추가

**수용 기준**
화면 캡처를 붙여넣거나 파일을 입력창 위로 끌어다 놓으면, 첨부 버튼을 거치지 않고도 첨부 목록에 항목이 추가되어야 한다.

**우선순위**
하
