기능적 차이점

| 구분             | 기존초안                           | 지금 작업한 버전                             |
| -------------- | ------------------------------ | ------------------------------------- |
| **API Key 관리** | 없음                             | API Key 입력, 저장, 삭제, 연결 테스트 기능 추가      |
| **로그인/사용자 기능** | 기본 프로필 표시 수준                   | Google 로그인 mock, 프로필 갱신, 사용자 상태 반영 추가 |
| **피드백 기능**     | 없음                             | 피드백 모달과 제출 기능 추가                      |
| **화면 폭 조절**    | 좌측/우측 패널 폭이 고정됨                | 사이드바와 Context 패널을 드래그해서 폭 조절 가능       |
| **AI 정제 방식**   | 선택 블록 전체를 하나의 결과로 정제           | 선택한 블록들을 각각 따로 정제                     |
| **정제 결과 확인**   | 정제 결과를 하나의 미리보기 박스로 확인         | 중앙패널에서 블록별로 원본/정제본을 비교하며 확인                  |
| **승인/거절 기능**   | 개별 승인·거절 없음                    | 블록마다 승인/거절 가능                         |
