# 0820_16 하위 사이드 채팅 일반 생성

## 목표

사이드 채팅 아래의 자식 채팅도 일반 또는 Temporary로 사용자가 선택해 만들 수 있게 한다.

## 범위

- 서버의 하위 채팅 Temporary 강제 규칙을 제거한다.
- 사이드 채팅 화면에도 일반·Temporary 생성 선택을 표시한다.
- 관련 테스트와 기획 문서를 갱신한다.

## 완료 기준

- [ ] 하위 사이드 채팅을 일반으로 만들 수 있다.
- [ ] Temporary 선택 시 기존 만료·정리 동작을 유지한다.
- [ ] 백엔드·프론트엔드 검증이 통과한다.
