# 0820_09 과거 채팅 참고와 출처 이동

- 상태: 계획 -> 이 문서는 나중에 구현하겠음(사용자의 허락을 받을 것)
- 왜? 블록 단위 편집을 수정하려고 계획 중이기 때문, 블록 단위로 편집이 되는 것은 제한적이고, 사용자가 드래그한 범위만 포함/제외하는 형태가 UX적으로 더 좋을듯 하기 때문이다. 근데 이걸 먼저 구현한 후 09번 구현을 해야하기 때문에 나중에 구현하도록 계획하는 것이다.

## 목표

현재 질문과 관련 있는 **본인 과거 대화**를 찾아 답변 생성에 참고하고, 실제로 쓴 원문 일부와 이동 경로를 답변 아래에서 확인할 수 있게 한다.

## 확정 범위

- 참고 대상은 현재 사용자 본인의 대화로 한정한다.
- 에이전트는 참고 대상인 본인 과거 대화 전체에서 필요할 때 관련 내용을 찾을 수 있다.
- 사용자는 과거 대화의 특정 메시지 또는 향후 드래그로 고른 범위를 멘션해 이번 질문에 명시적으로 포함할 수 있다.
- 사용자 멘션은 에이전트의 전체 참고 범위를 제한하지 않고, 이번 답변에서 우선 참고할 대상을 지정하는 수단이다.
- 삭제됐거나 현재 접근할 수 없는 대화는 검색 결과와 답변 출처에서 제외한다.
- 답변에 실제로 쓴 대화 내용은 당시 버전으로 스냅샷 저장한다.
- 원문이 이후 수정돼도, 해당 답변이 어떤 내용을 근거로 했는지 추적할 수 있어야 한다.
- 출처 카드에는 대화 제목, 발화 일부, 작성 시점, 사용된 블록 수를 표시한다.
- 출처 카드를 누르면 해당 대화·브랜치·메시지 위치로 이동하고, 원문 메시지를 강조한다.

## 제외 범위

- 공유 대화와 공유 프로젝트의 검색·참고 권한 모델
- 사용자 성향·선호 등을 장기 보관하는 개인화 메모리
- 자동으로 모든 과거 대화를 현재 AI 입력에 넣는 동작



## 사용자 흐름

1. 사용자가 메시지를 전송한다.
2. 사용자는 필요하면 과거 대화의 메시지 또는 드래그 범위를 멘션한다.
3. 시스템은 본인 대화 전체에서 관련 내용을 찾고, 사용자 멘션을 우선 참고한다.
4. 실제 답변에 사용한 과거 대화 일부만 참고 Context와 출처로 기록한다.
5. 답변 아래 `과거 대화 참고` 영역에 실제 사용한 출처 카드를 표시한다.
6. 사용자가 카드를 누르면 원문 대화의 해당 위치로 이동한다.



## 구현 원칙

- 에이전트가 접근할 수 있는 본인 과거 대화 전체와 실제 AI 입력에 사용한 항목을 구분한다. 전체 대화 본문을 자동으로 AI 입력에 넣지 않는다.
- 사용자가 멘션한 메시지·범위는 이번 답변의 우선 참고 대상으로 처리한다. 멘션하지 않은 과거 대화도 에이전트가 필요에 따라 검색·참고할 수 있다.
- 답변마다 사용한 원문 블록 ID, 버전 ID, 당시 본문, 대화 ID, 브랜치 ID를 스냅샷으로 남긴다.
- 이동 대상이 삭제되었거나 더 이상 열 수 없으면 출처 카드는 남기되, 이동 동작 대신 해당 상태를 안내한다.
- 현재 대화의 Context 적용 구조와 별개로 저장하되, 답변 생성 시에는 같은 방식으로 명시적 Context를 전달한다.



## 완료 기준

- 본인 대화만 후보로 검색된다.
- 에이전트가 본인 과거 대화 전체에서 관련 내용을 찾되, 실제 답변에는 필요한 일부만 사용한다.
- 사용자가 멘션한 메시지·범위가 우선 참고 대상으로 반영된다.
- 삭제·접근 불가 대화는 후보와 출처에서 보이지 않는다.
- 답변 아래에서 실제 참고한 과거 대화 일부를 확인할 수 있다.
- 출처 카드를 누르면 정확한 대화·브랜치·메시지 위치로 이동한다.
- 원문 수정 후에도 과거 답변의 참고 스냅샷을 조회할 수 있다.



## 검증 방법

- 다른 사용자 대화, 삭제 대화, 존재하지 않는 대화가 검색·출처 결과에서 제외되는지 백엔드 테스트로 확인한다.
- 사용자 멘션이 우선 참고되고, 멘션하지 않은 본인 과거 대화도 필요 시 검색·참고할 수 있는지 확인한다.
- 답변 생성 뒤 저장된 출처 스냅샷이 당시 블록 버전과 본문을 유지하는지 확인한다.
- 프론트엔드 테스트로 출처 카드 표시와 클릭 이동·강조를 확인한다.
