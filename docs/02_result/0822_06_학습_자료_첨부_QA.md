# 학습 자료 첨부 QA

## 목표

트랜스포머 학습 텍스트를 첨부하고, 업로드 상태와 제거 동작을 점검한다.

## 범위

- `.txt` 파일 선택과 업로드 완료 상태
- 첨부 제거
- 전송 전 입력창 상태 유지

## 완료 기준

- 첨부 파일명·상태가 화면에 정확히 보인다.
- 제거 뒤 전송할 첨부 목록에서 사라진다.
- 오류는 수정·테스트·브라우저 재검증한다.

## 검증 방법

- 개인 정보가 없는 임시 학습 텍스트 파일을 사용한다.
- 로컬 외부 브라우저에서 파일 선택을 실행한다.

## 구현 결과

- 첨부 메뉴에서 사진 업로드와 파일 업로드를 구분해 표시하는 것을 확인했다.
- 파일 입력은 PDF·일반 텍스트·Markdown 형식을 허용하도록 설정되어 있다.

## 검증 결과

- 외부 브라우저에서 파일 업로드 선택창 호출까지 확인했다.
- 외부 브라우저 제어가 로컬 파일 전달을 차단해 실제 업로드·제거는 검증하지 못했다.

## 남은 제한 사항

- 실제 파일 첨부는 로컬 브라우저에서 수동으로 선택하거나, 파일 전달 권한이 있는 QA 환경에서 다시 확인해야 한다.
