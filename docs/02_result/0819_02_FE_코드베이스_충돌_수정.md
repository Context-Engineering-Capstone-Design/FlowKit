## 수정 내용

### 메시지 블록

- 각 메시지 블록에 생성 시각을 표시한다.
- 사용자 메시지도 버전이 2개 이상이면 이전·다음 버전으로 이동할 수 있다.
- 정제 대기 블록과 거절 블록의 왼쪽 테두리를 상태에 맞게 구분한다.

변경 경로:

- `frontend/src/components/MessageBlockItem.tsx`

### 정제 결과 상태와 전환 효과

- 거절한 정제 결과를 목록에서 지우지 않고 `거절됨` 상태로 유지한다.
- 대기 결과에는 `대기` 상태를 표시하고, 대기 상태에서만 승인·거절 버튼을 제공한다.
- 승인한 결과는 오른쪽으로 밀리며 접힌 뒤 목록에서 사라진다.
- 전체 승인 시 여러 항목이 짧은 간격으로 차례대로 사라진다.
- 마지막 승인 항목이 사라지면 정제 미리보기 영역을 서서히 닫는다.
- 승인된 메시지 블록은 적용 직후 잠깐 강조한다.
- 승인 API 처리가 끝난 뒤 최신 메시지 블록을 조회해 이전 내용이 다시 표시되는 순서 충돌을 막는다.

변경 경로:

- `frontend/src/api/conversation.ts`
- `frontend/src/components/ContextPanel.tsx`
- `frontend/src/components/MessageBlockItem.tsx`
- `frontend/src/index.css`
- `frontend/src/store/chatStore.ts`
- `frontend/src/types/api.ts`

### 전체 승인 부분 실패 처리

- 전체 승인 응답의 성공 목록과 실패 목록을 나눠 처리한다.
- 성공한 결과만 승인 상태로 반영하고, 실패한 결과는 목록에 남긴다.
- 일부 실패가 있으면 실패한 블록 수를 오류 메시지로 알린다.

변경 경로:

- `frontend/src/api/conversation.ts`
- `frontend/src/store/chatStore.ts`
