# 학습 대화 검색·최근 대화 탐색 QA

## 결과

검색 결과가 Project 폴더 안에만 있을 때 빈 결과로 잘못 보이는 문제와, 빠르게 대화를 바꿀 때 이전 응답이 마지막 선택을 덮을 수 있는 문제를 수정했다.

기준 코드 커밋: `d0d9156` (`fix(navigation): preserve latest chat selection`)

## 확인된 문제

- 검색 결과가 Project 대화뿐이면 최근 대화 영역이 `검색 결과가 없습니다`를 표시했고, 일치한 대화는 접힌 Project 폴더 안에 숨었다.
- 대화 A와 B를 연속으로 열 때 A의 응답이 더 늦게 끝나면, 마지막으로 선택한 B 대신 A의 제목·블록·활성 탭이 화면에 반영될 수 있었다.

## 구현

- 검색 중 일치하는 대화가 있는 Project 폴더는 자동으로 펼치고, 검색어를 지우면 사용자가 정한 접힘 상태로 돌아가게 했다.
- 검색 결과가 하나라도 있으면 최근 대화 영역의 빈 결과 문구를 표시하지 않게 했다.
- 패널별 대화 열기 요청에 최신 요청 식별자를 두어, 늦게 끝난 이전 상세·오류·피드백 응답이 현재 선택을 덮지 못하게 했다.
- Project 전용 검색과 A/B 연속 선택 순서 역전 회귀 테스트를 추가했다.

변경 경로:

- `frontend/src/components/Sidebar.tsx`
- `frontend/src/components/Sidebar.test.tsx`
- `frontend/src/store/chatStore.ts`
- `frontend/src/store/chatStore.test.ts`

## 검증

- 로컬 외부 브라우저에서 `Self-Attention` 검색 결과를 확인하고 검색어를 지웠다. 결과 1개가 표시되고, 지운 뒤 최근 대화 목록이 정상 복귀했다.
- 브라우저 오류 로그: 없음.
- Project 안에만 있는 일치 대화의 실제 브라우저 데이터는 만들거나 이동하지 않았다. 해당 경우는 단위 테스트로 검증했다.
- 대상 테스트: Sidebar·chatStore 67개 통과.
- 프런트엔드 전체 테스트: 28개 파일, 187개 통과.
- 린트와 프로덕션 빌드 통과. 기존 경고와 번들 크기 경고는 남아 있으며 이번 변경으로 새 경고는 추가되지 않았다.

## 제한 사항

- 새 대화 생성, 대화 삭제, 운영 데이터 삭제, 권한·비밀값, 결제·계정 설정은 실행하거나 변경하지 않았다.
