## 문제

기존 `gemini-2.5-flash` 모델은 신규 사용자에게 제공되지 않아 실제 호출 시 `404`가 발생했다. 또한 대체 모델은 temperature 같은 샘플링 값을 고정으로 사용해 전달한 값이 적용되지 않고 경고만 남았다.

## 수정 내용

### 1. 모델 교체

- 기본 모델을 `gemini-2.5-flash`에서 `gemini-3.6-flash`로 변경했다.
- 실제 사용 가능한 모델은 Google GenAI 클라이언트의 모델 목록 조회로 확인하도록 모델링 README에 안내를 추가했다.

### 2. 온도 설정 제거

- 답변·정제·제목 체인에서 역할별 temperature 인자를 제거했다.
- LLM 클라이언트의 `get_chat_model()`에서도 temperature 인자를 제거했다.
- 현재 모델에서 동작하지 않는 설정을 남기지 않아 호출 경고를 제거했다.
- 향후 다른 모델로 교체돼 temperature가 지원되면 LLM 클라이언트에 다시 추가하도록 주석으로 남겼다.

### 3. 실제 API 검증

커밋 설명에 따라 실제 Gemini API로 다음 기능을 확인했다.

- 채팅 제목 생성
- 블록별 정제
- 답변 생성

이 검증은 단위 테스트의 프롬프트 조립 검증과 달리, 모델 접근 가능성과 실제 응답 생성을 확인한 것이다.

## 완료 기준

- 기본 모델이 해당 API 키에서 실제로 호출 가능한 모델이다.
- 답변·정제·제목 체인에서 지원되지 않는 sampling 설정을 전달하지 않는다.
- 실제 API로 세 체인의 응답 생성을 확인한다.

## 검증 범위

커밋 설명에 실제 API 검증이 기록돼 있다. 단, 모델 제공 여부와 지원 파라미터는 외부 서비스 상태에 따라 변할 수 있으므로 이후 환경 변경 시 재확인이 필요하다.
