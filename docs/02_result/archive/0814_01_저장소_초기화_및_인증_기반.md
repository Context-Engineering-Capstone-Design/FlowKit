## 목표

개인 작업 폴더에 섞여 있던 프로젝트를 독립 `FlowKit` 저장소로 분리하고, 이후 MVP 개발의 기준이 될 기획 문서와 백엔드 인증 기반을 한 저장소에 배치한다.

## 구현 및 반영 항목

### 1. 독립 저장소와 기획 기준선

- `FlowKit` 독립 Git 저장소를 생성했다.
- 요구사항정의서, 백엔드 기능명세서, 최종보고서, 논문 리서치, UI 시안(`FlowKit_0520.html`)을 포함했다.
- 커밋 설명 기준으로 요구사항은 기능 요구사항 65개, 비기능 요구사항 19개를 기준선으로 삼았다.

### 2. 백엔드 초기 구조

- FastAPI, SQLAlchemy, PostgreSQL, Alembic 기반의 백엔드 뼈대를 생성했다.
- 환경 변수 예시, Docker Compose, 데이터베이스 연결, 공통 예외 처리, 의존성 주입 구조를 추가했다.
- 초기 Alembic 마이그레이션을 추가했다.

### 3. MVP 데이터 모델과 인증

- MVP 범위의 데이터 모델 13개를 정의했다.
- 사용자와 인증 세션을 위한 `users`, `auth_sessions` 모델을 포함했다.
- 채팅·브랜치·메시지·정제·Context 적용을 위한 초기 모델을 함께 정의했다.
- Google ID 토큰 검증, JWT 발급·갱신, 로그아웃, 사용자 프로필 조회·수정 등 인증 기능(BE-AUTH-001~010)을 구현했다.

### 4. 초기 테스트 기반

- 인증, 헬스 체크, ORM 모델 스모크 테스트 코드를 추가했다.
- 이 커밋 자체에는 테스트 실행 결과가 기록되어 있지 않으므로, 당시의 실제 실행 성공 여부는 이 문서에서 주장하지 않는다.
