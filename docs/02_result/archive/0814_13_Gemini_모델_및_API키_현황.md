## 목표

실제 모델 호환성 수정과 Gemini API 키 준비 상태를 개발환경 규약의 기준 정보와 진행표에 반영한다.

## 변경 내용

- 기본 모델을 `gemini-3.6-flash`로 명시했다.
- 신규 사용자에게 제공되지 않아 `404`가 발생하는 `gemini-2.5-flash`를 사용하지 않도록 기록했다.
- `GOOGLE_API_KEY` 발급 상태를 진행표에서 완료로 변경했다.
- 정제와 제목 생성은 고성능 모델보다 빠르고 경량인 Flash 계열 모델을 사용한다는 선택을 유지했다.
