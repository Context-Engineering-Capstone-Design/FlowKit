## 목표

대화, 메시지 블록 선택, Context 편집과 정제를 한 화면에서 이어서 수행하는 사용자 작업 화면을 구현한다.

## 구현 내용

### 1. 3단 작업 공간

- 좌측 사이드바, 중앙 대화 영역, 우측 Context 패널로 화면을 구성했다.
- 인증 상태에 따라 로그인 화면 또는 작업 공간을 표시한다.
- 메시지 블록을 선택하면 Context 패널을 열어 선택 내용을 편집할 수 있다.

### 2. 대화 및 브랜치 탐색

- 새 대화 생성, 대화 목록 조회, 브랜치 전환, 로그아웃을 사이드바에 배치했다.
- 대화 검색은 250ms 디바운스를 적용했다.
- 중앙 영역에서 대화 제목, 메시지 목록, 오류 상태, 입력창을 제공한다.
- Markdown 형식의 AI 응답을 렌더링하고, 메시지 재생성 동작을 연결했다.

### 3. Context 선택·편집·적용

- 각 메시지 블록에 선택 체크박스를 추가했다.
- 선택된 블록 수와 적용 대기 Context를 중앙 영역에 표시한다.
- 적용 대기 Context는 사용자가 직접 해제할 수 있다.
- Context 패널에서 빠른 편집 문구와 추가 지시문을 선택·입력할 수 있다.
- Context 적용 후 메시지를 전송하면 선택 상태와 적용 대기 Context를 자동으로 비운다.
- 브랜치를 전환할 때도 이전 브랜치의 선택·적용 상태를 초기화한다.

### 4. 블록 정제 검토 UX

- 원문과 정제문을 인라인으로 전환해 비교할 수 있게 했다.
- 정제 결과별 승인·거절, 전체 승인, 패널 닫기 동작을 제공한다.
- 승인 또는 거절 후 최신 블록 상태를 다시 조회한다.

### 5. AI 모델 API 키 전달 보완

- 모델링 패키지에 `configure()`를 추가했다.
- 백엔드 시작 시 설정값의 Google API 키를 모델링 패키지로 전달하도록 변경했다.
- 설정 객체만 읽고 모델링 코드가 환경 변수를 직접 참조하던 차이로 인해, 실행 중 AI 호출에 API 키가 전달되지 않던 문제를 보완했다.
