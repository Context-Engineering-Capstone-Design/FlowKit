# AI 응답 평가 및 버전 이동

- 문서 번호: 0819_01
- 날짜: 2026-08-19
- 기준 커밋: `dc8f28ebbea7b7dd116fa21ce879144622ef3568`
- 커밋 제목: `feat: AI 응답 평가·버전 이동 구현`
- 상태: 구현 완료

## 목표

사용자가 AI 답변에 좋아요·싫어요 평가를 남기고, 재생성으로 생긴 답변 버전 사이를 이동할 수 있게 한다.

## 구현 내용

### 1. AI 답변 평가 저장

- `ai_response_feedbacks` 테이블과 `like`·`dislike` 평가 enum을 추가했다.
- 사용자와 AI 메시지 블록 조합을 유일하게 제한해, 같은 답변에 사용자별 평가 하나만 유지한다.
- 사용자 또는 메시지 블록이 삭제되면 연결된 평가는 함께 삭제된다.
- Alembic 마이그레이션 `0c50d3ec01f2_add_ai_response_feedback.py`를 추가했다.

### 2. 평가 API

- AI 답변 평가 조회 API를 추가했다.
- 평가 저장 API는 좋아요·싫어요의 신규 저장과 변경을 지원한다.
- 같은 버튼을 다시 누르면 `null`을 보내 기존 평가를 해제한다.
- 사용자 메시지 블록 평가 요청은 거절하고, 허용되지 않은 평가는 검증 오류로 처리한다.

### 3. 프론트엔드 평가 UI

- AI 답변에만 좋아요·싫어요 버튼을 표시한다.
- 버튼을 다시 누르면 평가가 해제되며, 선택된 평가는 시각적으로 구분한다.
- 대화 또는 브랜치를 열 때 각 AI 답변의 저장된 평가를 조회해 상태 저장소에 반영한다.

### 4. 답변 버전 이동

- 메시지 블록 응답에 현재 버전 번호를 포함했다.
- 재생성으로 버전이 둘 이상인 AI 답변에서 이전·다음 버튼과 현재 위치를 표시한다.
- 기존 버전 조회·현재 버전 변경 API를 프론트엔드에 연결했다.
- 선택한 버전으로 메시지 본문과 현재 버전 표시를 즉시 갱신한다.

## 완료 기준

- AI 답변에 대한 사용자별 좋아요·싫어요 평가를 저장·변경·해제할 수 있다.
- 사용자 메시지에는 평가를 남길 수 없다.
- 재생성된 AI 답변의 버전을 이전·다음으로 이동하고 현재 본문을 변경할 수 있다.
