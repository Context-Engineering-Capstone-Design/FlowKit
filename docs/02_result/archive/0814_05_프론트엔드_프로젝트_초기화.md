## 목표

FlowKit의 웹 클라이언트 개발을 위한 React 기반 프로젝트와 백엔드 연동의 공통 기반을 만든다.

## 구현 항목

### 1. 프론트엔드 프로젝트

- Vite, React, TypeScript 기반 프로젝트를 `frontend/`에 생성했다.
- Tailwind CSS v4를 설정했다.
- Vite 개발 서버 포트는 `5173`, 소스 경로 별칭은 `@`로 정했다.
- npm과 `package-lock.json`을 의존성 관리 기준으로 추가했다.

### 2. UI 토큰과 초기 화면

- UI 시안의 다크 테마 색상을 `frontend/src/index.css`의 Tailwind 토큰으로 정의했다.
- 초기 `App` 화면에서 백엔드 `/health` 연결 상태를 표시하도록 구현했다.
- 아이콘과 마크다운 렌더링을 위한 `lucide-react`, `react-markdown` 의존성을 포함했다.

### 3. API·상태 관리 기반

- 백엔드 응답 형식에 맞는 TypeScript 타입을 `types/api.ts`에 정의했다.
- 인증, 채팅, 브랜치 API 래퍼의 기본 구조를 만들었다.
- Zustand 기반 채팅 상태 저장소의 기본 구조를 추가했다.

### 4. 인증 토큰 재발급 보호

- axios 클라이언트가 요청마다 액세스 토큰을 첨부하도록 구성했다.
- `401` 응답 시 refresh token으로 재발급한 뒤 원래 요청을 재시도하도록 구성했다.
- 여러 요청이 동시에 만료돼도 토큰 재발급은 한 번만 수행하도록 묶었다. refresh token 회전 방식에서 폐기된 토큰을 중복 사용해 전체 세션이 종료되는 문제를 방지하기 위한 결정이다.
