## 구현 내용

- `createChatStore()` 팩토리와 `ChatPaneContext`를 추가했다. 메인과 우측 패널은 각자 독립된 대화 상태, 메시지 목록, 입력창, 모델·웹 검색·추론 설정, 첨부 상태를 쓴다.
- `Workspace`를 메인·사이드 2분할 구조로 바꿨다. 사이드 패널은 첫 파생 대화가 열릴 때만 표시되고, 데스크톱에서 폭을 조절할 수 있다. 좁은 화면에서는 메인만 보인다.
- 사이드 채팅과 블록 기준 브랜치 생성 결과를 우측 패널로 보낸다. 우측 패널이 이미 있으면 같은 store의 탭으로 추가한다.
- 기존 `ChatTabBar`를 각 `ChatPane` 안으로 옮겼다. 마지막 사이드 탭을 닫으면 우측 패널을 닫는다.
- Context 편집을 같은 패널의 `Context 편집` 탭으로 표시한다. 적용 버튼은 해당 패널의 Context 상태에 반영하고 원래 채팅 화면으로 돌아간다.
- 기존 좁은 Context 패널의 사이드 채팅 생성·목록 UI를 제거했다. 좌측 `대화 구조`의 사이드 노드는 우측 패널에서 연다.
- store 두 인스턴스의 입력 상태가 섞이지 않는 자동 테스트를 추가했다.
