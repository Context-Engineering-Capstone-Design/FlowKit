# 학습 대화 스트림 재연결·세션 정리 QA

## 결과

- 기준 코드 커밋: `cace9d9` (`fix: isolate AI stream sessions and retries`)
- 메인·사이드 패널별로 스트림 연결, 전달 시간 임시값, 목록 갱신 타이머·폴링과 요청 최신성 값을 분리했다.
- 로그아웃·세션 만료 시 모든 패널의 진행 중 스트림을 중단하고, 실시간 채널·재접속·목록 갱신을 함께 멈춘다.
- 늦게 끝난 목록·입력 보조·정제 시작·정제 승인/거절·일괄 처리 결과는 시작 당시 세션, 채팅, 브랜치, 정제 작업이 그대로일 때만 반영한다.
- Temporary Chat 정리 대기 중 세션이 바뀌면 새 빈 탭을 다시 만들지 않는다.
- 스트림 재접속 누적 본문은 덧붙이지 않고 `snapshot`으로 교체한다. 완료 상태 없이 SSE가 끝나면 클라이언트가 연결 실패로 처리한다.
- 서버가 실시간 스트림을 이미 잃은 경우에도 DB를 다시 읽어, 구독 직전에 완료된 작업을 실패로 잘못 표시하지 않는다.
- 실패한 generate 작업의 최신 재시도 대상은 대화 상세·실시간 갱신·완료 이벤트에서 같은 사용자 질문 아래에 유지한다.
