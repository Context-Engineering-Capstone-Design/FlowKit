# 0820_12 사이드바 생성 상태와 완료 도트

- 상태: 구현 완료 (실행 검증 보류)

## 목표

사용자가 다른 대화로 이동한 뒤에도, 사이드바 목록에서 답변 생성 중인 대화와 새 답변이 완료됐지만 아직 확인하지 않은 대화를 구분해 보여준다.

## 상태와 표시

| 상태 | 표시 | 해제 시점 |
| --- | --- | --- |
| 다른 대화에서 답변 생성 중 | 제목 오른쪽의 작은 점 3개 애니메이션 | 생성 완료·실패·취소 |
| 다른 대화의 새 답변 완료, 아직 미확인 | 제목 오른쪽의 강조색 완료 도트 | 해당 대화를 열어 확인 |
| 현재 보고 있는 대화 | 표시하지 않음 | - |

- 완료 도트는 단순 완료 상태가 아니라, 사용자가 아직 확인하지 않은 새 답변을 뜻한다.
- 생성 실패·취소는 완료 도트로 바꾸지 않는다.
- 상태 표시에는 호버 안내나 툴팁을 추가하지 않는다.

## 범위

### 마일스톤 A · 대화 목록 상태

- [x] A1. 대화 목록 응답에 대화별 생성 상태와 미확인 완료 여부를 추가한다.
- [x] A2. 사용자별 대화 마지막 확인 시각을 저장한다.
- [x] A3. 답변 생성 완료 시각이 마지막 확인 시각보다 뒤면 미확인 완료 상태로 계산한다.
- [x] A4. 대화에 생성 중인 AI 답변이 하나라도 있으면 생성 중 상태로 계산한다.
- [x] A5. 생성 실패·취소·대화 삭제 뒤 목록 상태를 정확히 갱신한다.

### 마일스톤 B · 상태 갱신

- [x] B1. 사용자가 다른 대화를 열어도 기존 대화의 답변 생성 연결을 유지한다.
- [x] B2. 생성 완료·실패·취소 이벤트가 도착하면 해당 대화의 목록 상태를 갱신한다.
- [x] B3. 생성 중인 대화가 하나라도 있을 때만 목록 상태를 짧은 주기로 다시 조회하고, 모두 끝나면 중지한다.
- [x] B4. 대화를 열면 마지막 확인 시각을 갱신하고 완료 도트를 즉시 제거한다.

### 마일스톤 C · 사이드바 UI

- [x] C1. 생성 중인 다른 대화 제목 오른쪽에 점 3개 애니메이션을 표시한다.
- [x] C2. 미확인 완료 대화 제목 오른쪽에 작은 강조색 도트를 표시한다.
- [x] C3. 현재 보고 있는 대화에는 생성 중·완료 도트를 표시하지 않는다.
- [x] C4. 좁은 화면과 긴 대화 제목에서도 상태 표시가 잘리지 않게 한다.

### 마일스톤 D · 검증

- [ ] D1. A 대화에서 답변 생성 뒤 B 대화로 이동하면 A에 생성 중 표시가 나오는지 검증한다.
- [ ] D2. A의 생성 완료 뒤 미확인 완료 도트로 전환되는지 검증한다.
- [ ] D3. A를 열면 완료 도트가 즉시 사라지고 마지막 확인 시각이 갱신되는지 검증한다.
- [ ] D4. 생성 실패·취소에는 완료 도트가 생기지 않는지 검증한다.
- [ ] D5. 프론트엔드 자동 테스트와 브라우저에서 대화 이동·생성·완료 흐름을 확인한다.

## 완료 기준

- 다른 대화의 생성 중 상태와 미확인 완료 상태가 사이드바에서 구분된다.
- 사용자가 새 답변이 완료된 대화를 열면 완료 도트가 사라진다.
- 생성 실패·취소·삭제 뒤 잘못된 표시가 남지 않는다.
- 생성 중인 대화가 없을 때는 상태 갱신용 반복 조회가 실행되지 않는다.

## 구현 결과 (2026-08-20)

- 기준 커밋: `56b943e` (`feat(sidebar): 답변 생성과 미확인 완료를 표시한다`)
- `chat_read_states`에 사용자·대화별 마지막 확인 시각을 저장하고, 목록 API가 생성 중 여부와 미확인 완료 여부를 함께 돌려준다.
- 대화 상세를 열면 확인 시각을 갱신한다. 완료 작업만 도트 대상이며 실패·취소는 제외한다.
- 프론트는 생성 중일 때만 2.5초 간격으로 목록을 새로 읽고, 다른 대화에는 점 3개 또는 완료 도트를 표시한다. 현재 대화에는 표시하지 않는다.

### 검증 제한

- 수정 백엔드 파일은 `py_compile`을 통과했다.
- 전체 프론트 빌드는 동시에 작업 중인 범위 선택 기능의 `ChatArea.tsx` 오류로 실행하지 못했다. 이 작업 변경과 무관한 오류라 수정하지 않았다.
- 백엔드 pytest와 실제 브라우저 대화 이동 검증은 현재 환경 의존성·서버 미실행으로 보류했다.
