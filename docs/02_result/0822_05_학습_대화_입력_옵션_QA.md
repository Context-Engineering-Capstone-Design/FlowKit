# 학습 대화 입력 옵션 QA

## 목표

학습 질문을 보내기 전 웹 검색·추론 수준·모델 선택을 바꾸고, 화면 동작과 오류 처리를 점검한다.

## 범위

- 웹 검색 `자동·끔·항상` 선택
- 추론 수준 선택
- 모델 선택과 비활성 상태

## 완료 기준

- 각 옵션을 명확히 바꾸고 현재 선택값을 확인한다.
- 오류는 재현 후 수정·테스트·브라우저 재검증한다.

## 검증 방법

- 로컬 외부 브라우저에서 학습 대화 초안의 옵션을 조작한다.
- 사용자 API 키가 필요한 실제 AI 호출은 실행하지 않는다.

## 구현 결과

- 웹 검색을 `항상`으로, 추론 수준을 `높음`으로, 모델을 Terra로 각각 변경했다.
- 선택 메뉴에는 웹 검색 3단계와 Terra·Sol·Luna 모델 설명이 표시됐다.

## 검증 결과

- 외부 브라우저에서 각 변경 직후 입력창의 현재 선택값을 확인했다.
- 새로고침 뒤 입력 옵션은 기본값인 `자동`·`중간`·Luna로 돌아왔다. 현재 설계는 대화 전송 시점의 입력값을 스냅샷으로 저장하며, 빈 초안의 옵션을 새로고침 간 보존하지 않는다.

## 남은 제한 사항

- OpenAI API 키 없이 옵션을 실제 모델 호출까지 전달하는 성공 경로는 확인하지 않았다.
