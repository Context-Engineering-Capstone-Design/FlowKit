# 0820_07 긴 대화 목차 탐색

- 상태: 구현 완료
- 기준: 2026-08-20 논의

## 목표

현재 브랜치에서 긴 대화를 다시 찾을 수 있도록, 대화 턴 단위의 목차와 미리보기를 제공한다. 사용자가 입력 중인 내용, 선택한 Context, 브랜치 상태는 목차를 열거나 이동해도 바꾸지 않는다.

## 확정된 UX

- 목차 항목 하나는 사용자 질문 1개와 그에 이어진 AI 답변을 묶은 대화 턴이다.
- 항목 제목은 AI가 새로 요약하지 않고, 사용자 질문의 앞부분을 사용한다. 빈 질문이나 시스템 성격의 블록은 항목을 만들지 않는다.
- 현재 브랜치의 대화만 보여준다. 다른 브랜치의 턴은 섞지 않는다.
- 대화 영역에 세로 스크롤이 생긴 경우, 화면 가장자리에 얇은 목차 레일을 표시한다.
- 레일 또는 목차 항목에 마우스를 올리면 질문 제목과 AI 답변의 첫 1~2줄을 팝업으로 보여준다.
- 항목을 누르면 해당 사용자 질문 블록이 대화 영역에 보이도록 부드럽게 이동한다.
- 이동한 턴에 별도 강조 표시를 하지 않는다.

## 범위

### 마일스톤 A · 대화 턴 데이터 만들기

- [x] A1. 현재 브랜치의 `MessageBlock` 목록을 순서대로 읽어 사용자 질문을 시작점으로 한 대화 턴 목록을 만든다.
- [x] A2. 각 항목에 안정적인 식별자, 질문 블록 ID, 질문 제목, 답변 미리보기, 대화 안에서의 순서를 넣는다.
- [x] A3. 스트리밍 중인 답변은 현재까지 받은 본문으로 미리보기를 갱신한다.
- [x] A4. 질문 뒤에 답변이 아직 없으면 질문만 있는 항목으로 안전하게 표시한다.

### 마일스톤 B · 목차 레일과 팝업

- [x] B1. 대화 영역의 실제 스크롤 높이가 화면 높이를 넘을 때만 `ConversationOutline`을 표시한다.
- [x] B2. 각 대화 턴의 세로 위치와 연결되는 얇은 레일 표시를 만든다. 현재 읽는 위치와 가까운 항목은 시각적으로 구분한다.
- [x] B3. 마우스·키보드 포커스 시 질문 제목과 답변 첫 1~2줄을 보여주는 팝업을 만든다. 팝업은 화면 밖으로 나가지 않게 배치한다.
- [x] B4. 작은 화면에서는 레일을 숨기고, 기존 대화·입력 UI를 우선한다.

### 마일스톤 C · 이동과 접근성

- [x] C1. 목차 항목 선택 시 해당 질문 블록으로 부드럽게 스크롤한다.
- [x] C2. 이동 후에는 강조 효과, 선택 상태 변경, 입력창 포커스 변경을 하지 않는다.
- [x] C3. 레일과 팝업은 키보드로 포커스·선택할 수 있고, 항목의 질문 제목을 접근성 이름으로 제공한다.
- [x] C4. 대화가 추가·삭제·브랜치 전환될 때 항목 목록과 현재 위치 표시를 다시 계산한다.

### 마일스톤 D · 테스트와 화면 확인

- [x] D1. 턴 생성 로직에서 사용자 질문·AI 답변 묶기, 답변 없는 질문, 스트리밍 답변을 테스트한다.
- [x] D2. 스크롤이 없는 짧은 대화에서는 레일이 보이지 않고, 긴 대화에서는 항목·미리보기가 보이는지 컴포넌트 테스트를 추가한다.
- [x] D3. 항목 선택이 올바른 질문 블록으로 이동하고 입력·Context·브랜치 상태를 바꾸지 않는지 테스트한다.
- [x] D4. 데스크톱 브라우저에서 레일·팝업·부드러운 이동을 확인한다. 작은 화면에서 레일이 숨겨지는지도 확인한다. — 2026-08-21 QA에서 확인 완료(아래 "QA 후속 확인" 참고)

## 완료 기준

- 긴 현재 브랜치에서 사용자 질문 기준의 목차 레일이 나타난다.
- 항목 호버 또는 포커스에서 질문과 짧은 답변 미리보기를 볼 수 있다.
- 항목 선택은 해당 질문으로만 부드럽게 이동하며, 대화 상태를 바꾸지 않는다.
- 짧은 대화와 작은 화면에서는 기존 화면을 방해하지 않는다.
- 관련 자동 테스트와 브라우저 확인이 통과한다.

### 구현한 항목

- `frontend/src/lib/conversationOutline.ts` — 블록 목록에서 대화 턴 목록을 만드는 순수 함수. 질문 블록 ID를 식별자로 쓰고, 질문 바로 다음이 AI 답변일 때만 같은 턴으로 묶는다.
- `frontend/src/hooks/useConversationOutlineLayout.ts` — 대화 스크롤 영역을 관찰해 레일 표시 여부, 각 턴의 세로 위치 비율, 현재 읽는 턴을 계산한다. 스크롤·창 크기 변화와 함께 답변 스트리밍으로 콘텐츠 높이가 늘어나는 것도 `ResizeObserver`로 감지한다.
- `frontend/src/components/ConversationOutline.tsx` — 목차 레일과 호버·포커스 팝업. 큰 화면(`lg` 이상)에서만 보이고, 항목을 누르면 해당 질문 블록으로 `scrollIntoView`만 호출한다(다른 화면 상태는 건드리지 않는다).
- [ChatArea.tsx](../../frontend/src/components/ChatArea.tsx) — 대화 스크롤 영역을 감싸는 래퍼를 추가해 `ConversationOutline`을 얹었다.
