# 0821_08 작업 화면 렌더링 복구

## 목표

로그인 뒤 `Workspace`가 상태 누락으로 전체 화면을 대체하지 않게 한다.

## 범위

- 첨부 초안 상태가 일시적으로 없더라도 작업 화면이 렌더링되게 한다.
- 렌더링 오류가 사라지는지 브라우저와 프런트 검증으로 확인한다.

## 완료 기준

- [x] 로그인 뒤 “화면을 표시하지 못했습니다” 오류가 나타나지 않는다.
- [x] 첨부 초안이 없는 새 대화가 정상 렌더링된다.
- [x] 이번 수정 범위의 테스트·build를 확인한다.

## 구현 결과

**기준 커밋:** `c3bebc0`

- 상태 모듈이 교체되는 순간 `draftAttachments`가 없더라도 작업 화면과 입력창이 빈 첨부 목록으로 렌더링되게 했다.
- 새 대화 첨부 허용 변경으로 더는 쓰지 않는 입력창의 `chatId` 선택을 제거했다.
