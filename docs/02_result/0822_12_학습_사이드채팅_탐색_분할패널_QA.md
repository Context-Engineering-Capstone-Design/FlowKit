# 학습 사이드 채팅 탐색·분할 패널 QA

## 결과

기존 학습 대화의 사이드 채팅 연결 칩이 메인 대화를 바꾸는 문제를 수정했다.

기준 코드 커밋: `66d327e` (`fix(side-chat): open linked chats in side panel`)

## 확인된 문제

메인 Self-Attention 대화에서 기존 `분기 3` 연결 칩을 누르면, 우측 Softmax 대화는 그대로이고 메인만 `분기 3`으로 전환됐다. 사이드 채팅은 우측 패널에서 여는 대화 구조 목록의 동작과 달랐다.

## 구현

- 메시지 아래 기존 사이드 채팅 연결 칩이 현재 패널의 대화 전환 대신 우측 패널 열기 함수를 호출하게 바꿨다.
- 단위 테스트를 우측 패널 오프너 호출 기준으로 바꿨다.

변경 경로:

- `frontend/src/components/MessageBlockItem.tsx`
- `frontend/src/components/MessageBlockItem.test.tsx`

## 검증

- 로컬 외부 브라우저에서 Self-Attention 메인 대화와 Softmax·분기 학습 사이드 대화를 사용했다.
- 수정 전 `분기 3` 연결 칩은 메인을 전환하고 우측 패널을 유지하는 것을 재현했다.
- 수정 후 `새 사이드 채팅`, `분기 3` 연결 칩을 각각 눌렀다. 메인은 Self-Attention 대화를 유지했고, 우측 패널만 해당 사이드 대화로 전환됐다.
- 대화 구조 목록의 `분기 3`도 동일하게 우측 패널에서 열렸다.
- 메인과 우측 패널의 탭을 따로 전환한 뒤에도 각 패널의 선택 상태와 내용이 독립적으로 유지됐다.
- 브라우저 오류 로그: 없음.
- 프런트엔드 전체 테스트: 28개 파일, 185개 통과.
- 린트와 프로덕션 빌드 통과. 기존 경고와 번들 크기 경고는 남아 있으며 이번 변경으로 새 경고는 추가되지 않았다.

## 제한 사항

- 새 사이드 채팅 생성과 임시 대화·대화 삭제 흐름은 실행하지 않았다.
- 운영 데이터 삭제, 권한·비밀값, 결제·계정 설정은 변경하지 않았다.
