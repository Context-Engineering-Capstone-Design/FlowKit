## QA 후속 확인 (2026-08-21)

`0820_19` QA에서 처음 실제 Chrome으로 확인했다. 코드 변경 없음.

- 손자 단계(사이드 채팅의 사이드 채팅) 생성 화면에도 "새 사이드 채팅 만들기"·"Temporary" 두 옵션이 모두 활성화돼 있음을 확인했다. "Temporary"는 켜고 끄는 토글이며, 토글 상태로 "새 사이드 채팅 만들기"를 눌러야 실제로 생성된다(별도 선택 모달 방식이 아니다).
- 손자 단계에서 Temporary를 켜지 않고 만들면 일반 채팅으로 만들어져 좌측 "대화 구조"에 나타나고, 토글을 켜고 만들면 탭에 "Temporary Chat" 표시가 붙고 목록에서는 제외됨을 확인했다. 예전의 "손자는 무조건 Temporary" 강제 규칙이 실제로 풀렸다.
- 증손자 이상 깊이는 시간 관계상 확인하지 못했다.
