# 0819_08 Cursor 내부 브라우저 로컬 개발 로그인

상태: 구현 완료

기준 커밋: `b654681`

## 목표

Google OAuth가 차단되는 Cursor 내부 브라우저에서도 로컬 FlowKit 화면과 API를 검증할 수 있도록 개발 환경 전용 로그인을 제공한다.

## 구현 결과

### 백엔드

- `DEV_LOGIN_ENABLED`의 기본값을 `false`로 추가했다.
- `POST /api/auth/dev`에서 고정된 로컬 개발 사용자와 기존 형식의 accessToken·refreshToken을 발급한다.
- 기능이 켜져 있어도 실제 연결 주소가 `127.0.0.1`, `::1`, `localhost`인 요청만 허용한다.
- 비활성화 상태와 로컬이 아닌 요청에는 `404 DEV_LOGIN_UNAVAILABLE`을 반환한다.
- 기존 Google 로그인, 토큰 갱신, 로그아웃 경로는 유지했다.

### 프론트엔드

- Vite 개발 모드이면서 `VITE_DEV_LOGIN_ENABLED=true`일 때만 `로컬 개발 로그인` 버튼을 표시한다.
- 개발 로그인으로 받은 토큰은 기존 로그인과 같은 저장·자동 갱신 흐름을 사용한다.
- 운영 빌드에서는 개발 로그인 버튼 문구가 포함되지 않는 것을 확인했다.

### 환경 설정과 안내

- 백엔드·프론트엔드 `.env.example`에는 기본 비활성화 값을 기록했다.
- 현재 로컬 `.env`에서만 두 기능 값을 `true`로 설정했다. `.env`는 Git에 포함되지 않는다.
- FlowKit 로컬 실행 안내서에 Cursor 내부 브라우저 사용 절차와 운영 환경 주의사항을 추가했다.

## 남은 제한 사항

- Cursor 내부 브라우저에서 버튼을 직접 누르는 최종 확인은 사용자 환경에서 진행해야 한다.
- 개발 로그인은 Google 인증을 검증하지 않는다. 배포 환경에서는 `DEV_LOGIN_ENABLED`와 `VITE_DEV_LOGIN_ENABLED`를 넣지 않거나 반드시 `false`로 둔다.
- 동시 구현 중인 AI 실패 복구 작업이 완료되면 백엔드 전체 테스트를 다시 실행해야 한다.
