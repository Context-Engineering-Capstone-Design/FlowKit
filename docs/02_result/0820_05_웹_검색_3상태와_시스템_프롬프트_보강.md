## 배경

### 1. 웹 검색 토글이 명세를 어기고 있다

`기획 문서/AI기능명세서/3.5 입력 보조 처리.md`의 AI-SEARCH-001은 "검색을 끈 요청이면 도구를 붙이지 않는다"고 못박는다. 그런데 실제 코드([`modeling/chains/answer.py`](../../modeling/chains/answer.py) 80~86행)는 답변 생성마다 `auto_web_search=True`를 고정으로 넘기고, [`modeling/llm.py`](../../modeling/llm.py)의 `get_chat_model`(97행)은 `web_search_enabled or (auto_web_search and model.supports_web_search)` 조건으로 도구를 붙인다. 세 모델(Sol·Terra·Luna) 모두 `supports_web_search=True`라서 이 조건은 토글 상태와 무관하게 항상 참이 된다. 토글을 꺼도 검색 도구가 계속 붙는다.

이 상태는 우연이 아니라 `docs/02_result/0820_02_...md`(마일스톤 D5)가 남긴 미완료 항목이다. "모델에 검색 도구를 항상 제공한다"만 구현됐고, "모델이 필요할 때만 검색을 쓴다", "버튼은 명시적 선택 수단으로 유지한다"는 구현되지 않았다. 이번 문서가 그 나머지를 마무리한다.

### 2. 시스템 프롬프트가 3줄뿐이다

[`modeling/prompts/answer.py`](../../modeling/prompts/answer.py)의 `SYSTEM`은 "사용자 언어로 답한다 / 지어내지 않는다 / 필요하면 마크다운을 쓴다" 세 줄이 전부다. 오늘 날짜, 답 길이 기준, 서식 세부 규칙이 없다. `기획 문서/AI기능명세서/3.2 답변 생성.md`(AI-ANSWER-001)의 명세 문구도 코드와 똑같이 세 줄이라, 이 부분은 코드뿐 아니라 명세 자체의 공백이다.

## 목표

1. 웹 검색을 **자동 / 항상 / 끄기** 세 상태로 만들어 사용자 통제권을 실제로 되돌려준다. "끄기"는 반드시 검색 도구를 붙이지 않는다.
2. 시스템 프롬프트에 오늘 날짜, 답 길이 기준, 서식 규칙을 더한다.
3. 관련 기획 문서(AI-SEARCH-001, BE-INPUT-004, FE-INPUT-004, AI-ANSWER-001)를 이번 설계에 맞게 고친다.

## 확정할 설계

### 세 상태의 뜻

| 상태 | 도구 제공 | 실제 호출 | 화면 표시 |
| --- | --- | --- | --- |
| 자동 | 붙인다 | 모델이 질문을 보고 스스로 판단 | 기본값 |
| 항상 | 붙인다 | `tool_choice`로 반드시 쓰도록 강제 | 강조 표시 |
| 끄기 | 붙이지 않는다 | 검색 자체가 불가능 | 꺼짐 표시 |

- **기본값은 "끄기"로 둔다.** "사용자 통제권 유지"라는 목표에 맞춰, 검색(외부 호출·지연 시간·비용)은 사용자가 명시적으로 켜야 일어나게 한다. 지금 화면의 `webSearchEnabled` 초기값(`false`)과도 자연스럽게 이어진다.
- **"항상"의 강제 방식**: OpenAI Responses API는 `tool_choice`로 특정 도구 사용을 강제할 수 있다. `_SEARCH_TOOL = {"type": "web_search"}`와 짝을 맞춰 `tool_choice={"type": "web_search"}`를 함께 넘긴다. **이 강제가 실제로 동작하는지는 실제 키로 확인해야 한다** — OpenAI 커뮤니티에 `web_search`/`web_search_preview` 이름 불일치로 `tool_choice` 요청이 거부된 사례가 보고돼 있다. 이번 구현은 도구 이름과 `tool_choice` 이름을 동일하게(`web_search`) 맞춰 그 문제를 피하지만, 검증 전까지는 위험으로 남긴다.

### 이름

- 모델링·백엔드·프론트엔드 모두 `webSearchEnabled: boolean`을 `webSearchMode: "off" | "auto" | "always"`로 바꾼다. 하위 호환 없이 한 번에 바꾼다(사용자 지정, 별도 승인 완료 — CLAUDE.md 기획 문서 수정 원칙의 예외).
- 저장된 옛 `AiResponseJob.inputSnapshot`(JSON)에는 `webSearchEnabled` 키만 있다. 재생성 시 이미 있는 `AiInputSnapshotIncompleteError`(필수 키 검사)가 이런 옛 스냅샷을 안전하게 막아준다 — 이 서비스는 아직 운영 이력이 없어 실제 영향은 없다.
