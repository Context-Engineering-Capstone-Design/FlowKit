## 2.7 Context 적용 요구사항

### REQ-045 · 정제된 Context 미리보기

사용자는 정제된 Context를 다음 질문에 적용하기 전에 확인할 수 있어야 한다.

입력 | Context 정제 완료
결과 | 미리보기 표시
수용 기준 | 정제된 Context는 별도 카드 또는 미리보기 영역에 표시되어야 한다.
우선순위 | 상

### REQ-046 · 정제된 Context 적용

사용자는 정제된 Context를 다음 질문에 적용할 수 있어야 한다.

입력 | 이 Context로 질문하기 버튼 클릭
결과 | Context 적용
수용 기준 | 적용 후 다음 질문은 선택·정제된 Context를 기반으로 처리되어야 한다.
우선순위 | 상

### REQ-047 · 적용 중인 Context 표시

사용자는 현재 어떤 Context가 적용 중인지 확인할 수 있어야 한다.

입력 | Context 적용
결과 | Context pill 표시
수용 기준 | 입력창 위에 "Context 적용 중" 상태가 표시되어야 한다.
우선순위 | 상

### REQ-048 · 적용 중인 Context 해제

사용자는 현재 적용된 Context를 해제할 수 있어야 한다.

입력 | Context pill의 해제 버튼 클릭
결과 | Context 적용 해제
수용 기준 | 해제 버튼 클릭 시 Context pill이 사라지고 적용 상태가 해제되어야 한다.
우선순위 | 중
