## 2.10 사용자 설정 요구사항

### REQ-058 · 사용자 프로필 메뉴 표시

사용자는 좌측 하단의 프로필 영역에서 계정 관련 메뉴를 열 수 있어야 한다.

입력 | 프로필 영역 클릭
결과 | 프로필 팝업 표시
수용 기준 | 사용자 정보, API 키 관리, 피드백 남기기, 로그아웃 메뉴가 표시되어야 한다.
우선순위 | 중

### REQ-059 · 사용자 정보 관리

사용자는 이름, 이메일, 메모 정보를 입력하거나 수정할 수 있어야 한다.

입력 | 사용자 정보 메뉴 클릭
결과 | 사용자 정보 모달 표시
수용 기준 | 이름/닉네임, 이메일, 메모 입력란과 저장 버튼이 표시되어야 한다.
우선순위 | 중

### REQ-060 · API 키 관리

사용자는 API 키를 입력, 저장, 삭제할 수 있어야 한다.

입력 | API 키 관리 메뉴 클릭
결과 | API 키 관리 모달 표시
수용 기준 | API 키 입력창, 보기/숨기기 버튼, 저장 버튼, 삭제 버튼이 제공되어야 한다.
우선순위 | 중

### REQ-061 · API 연결 확인

사용자는 등록한 API 키의 연결 상태를 확인할 수 있어야 한다.

입력 | 연결 확인 버튼 클릭
결과 | 연결 결과 표시
수용 기준 | 연결 성공 또는 실패 결과가 별도 메시지 영역에 표시되어야 한다.
우선순위 | 하

### REQ-062 · API 키 미등록 오류 표시

API 키가 등록되지 않은 상태에서 메시지를 전송할 경우 사용자에게 안내해야 한다.

입력 | API 키 미등록 상태에서 메시지 전송
결과 | 오류 배너 표시
수용 기준 | API 키 등록 필요 안내가 상단 오류 배너로 표시되어야 한다.
우선순위 | 중

### REQ-063 · 피드백 제출

사용자는 서비스 사용 중 오류나 개선 의견을 제출할 수 있어야 한다.

입력 | 피드백 남기기 메뉴 클릭
결과 | 피드백 모달 표시
수용 기준 | 피드백 유형 선택, 내용 입력, 제출 버튼이 제공되어야 한다.
우선순위 | 하
