## 2.3 브랜치 관리 요구사항

### REQ-007 · 브랜치 목록 확인

사용자는 현재 대화에서 생성된 브랜치 목록을 확인할 수 있어야 한다.

**입력**
좌측 사이드바 확인

**결과**
Main 및 하위 브랜치 목록 표시

**수용 기준**
"현재 대화 — 브랜치" 영역에 Main과 생성된 브랜치가 표시되어야 한다.

**우선순위**
상

---

### REQ-008 · 브랜치 전환

사용자는 브랜치 항목을 클릭하여 다른 대화 흐름으로 이동할 수 있어야 한다.

**입력**
브랜치 항목 클릭

**결과**
선택한 브랜치 메시지 표시

**수용 기준**
선택된 브랜치가 활성화되고 중앙 메시지 영역이 해당 브랜치 내용으로 변경되어야 한다.

**우선순위**
상

---

### REQ-009 · 브랜치 생성 모달 제공

사용자는 브랜치 생성 시 브랜치 이름, 분기 지점, 포함할 Context 블록을 설정할 수 있어야 한다.

**입력**
브랜치 생성 버튼 클릭

**결과**
브랜치 생성 모달 표시

**수용 기준**
모달에는 브랜치 이름 입력, 분기 지점 선택, Context 블록 선택 영역이 포함되어야 한다.

**우선순위**
상

---

### REQ-010 · 선택 Context 기반 브랜치 생성

사용자는 선택한 블록 또는 Context를 기반으로 새 브랜치를 생성할 수 있어야 한다.

**입력**
이 Context로 브랜치 생성 버튼 클릭

**결과**
새 브랜치 생성

**수용 기준**
브랜치 생성 후 좌측 브랜치 목록에 새 항목이 추가되어야 한다.

**우선순위**
상

---

### REQ-011 · 브랜치 생성 시 Context 요약 표시

사용자는 브랜치 진입 시 해당 브랜치의 출발 Context를 확인할 수 있어야 한다.

**입력**
브랜치 진입

**결과**
Context 요약 블록 표시

**수용 기준**
브랜치 화면 상단에 Context 요약 블록과 Context 요약 배지가 표시되어야 한다.

**우선순위**
중

---

### REQ-012 · 원본 Context 위치 이동

사용자는 브랜치 요약에서 원본 Context 블록 위치로 이동할 수 있어야 한다.

**입력**
Context 요약 pill 클릭

**결과**
원본 블록 위치 이동

**수용 기준**
요약 내 블록 항목 클릭 시 원본 메시지 위치가 강조되어야 한다.

**우선순위**
중
