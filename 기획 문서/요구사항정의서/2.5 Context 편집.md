## 2.5 Context 편집 요구사항

### REQ-022 · Context 편집 패널 열기/닫기

사용자는 우측 Context 편집 패널을 열거나 닫을 수 있어야 한다.

**입력**
Context 패널 버튼 또는 닫기 버튼 클릭

**결과**
패널 표시 상태 전환

**수용 기준**
버튼 클릭 시 우측 패널이 표시되거나 숨겨져야 한다.

**우선순위**
상

---

### REQ-023 · 선택된 블록 목록 확인

사용자는 우측 패널에서 선택한 블록 목록을 확인할 수 있어야 한다.

**입력**
메시지 블록 선택

**결과**
선택된 블록 목록 표시

**수용 기준**
선택된 각 블록은 역할 구분과 미리보기 텍스트 형태로 표시되어야 한다.

**우선순위**
상

---

### REQ-024 · 빠른 편집 지시 선택

사용자는 자주 사용하는 편집 지시를 버튼으로 선택할 수 있어야 한다.

**입력**
빠른 편집 버튼 클릭

**결과**
지시문 자동 입력

**수용 기준**
버튼 클릭 시 AI 편집 지시 입력창에 해당 문구가 자동 삽입되어야 한다.

**우선순위**
상

---

### REQ-025 · 자연어 AI 편집 지시 입력

사용자는 선택된 블록을 어떻게 정리할지 자연어로 입력할 수 있어야 한다.

**입력**
편집 지시 입력창에 텍스트 입력

**결과**
지시문 입력

**수용 기준**
사용자가 입력한 지시문은 블록별 정제 실행 시 반영되어야 한다.

**우선순위**
상
