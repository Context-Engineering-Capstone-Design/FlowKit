## 2.4 메시지 블록 관리 요구사항

### REQ-013 · 기본 채팅 메시지 표시

사용자는 중앙 채팅 영역에서 사용자 질문과 AI 응답을 블록 단위로 확인할 수 있어야 한다.

**입력**
채팅 메시지 생성 또는 브랜치 로드

**결과**
메시지 블록 표시

**수용 기준**
각 메시지 블록에는 역할, 시간, 본문 내용이 표시되어야 한다.

**우선순위**
상

---

### REQ-014 · 메시지 블록 선택

사용자는 필요한 메시지 블록을 선택할 수 있어야 한다.

**입력**
체크박스 클릭 또는 선택 버튼 클릭

**결과**
블록 선택 상태 적용

**수용 기준**
선택된 블록은 시각적으로 강조되고 우측 Context 패널에 반영되어야 한다.

**우선순위**
상

---

### REQ-015 · 선택 블록 해제

사용자는 선택한 메시지 블록을 다시 해제할 수 있어야 한다.

**입력**
체크박스 재클릭 또는 패널 내 제거 버튼 클릭

**결과**
선택 목록에서 제거

**수용 기준**
선택 해제 시 강조 표시가 사라지고 선택 목록에서도 제거되어야 한다.

**우선순위**
상

---

### REQ-016 · 선택 블록 수 표시

사용자는 현재 선택한 메시지 블록 개수를 확인할 수 있어야 한다.

**입력**
블록 선택 또는 해제

**결과**
선택 개수 표시

**수용 기준**
선택된 블록이 1개 이상이면 상단 버튼과 우측 패널에 선택 수가 표시되어야 한다.

**우선순위**
중

---

### REQ-017 · 메시지 블록 복사

사용자는 메시지 블록의 텍스트를 복사할 수 있어야 한다.

**입력**
복사 버튼 클릭

**결과**
클립보드 복사

**수용 기준**
복사 버튼 클릭 후 복사 완료 알림이 표시되어야 한다.

**우선순위**
하

---

### REQ-018 · 메시지 블록 수정

사용자는 기존 메시지 블록을 직접 수정할 수 있어야 한다.

**입력**
수정 버튼 클릭, 텍스트 수정

**결과**
수정본 반영

**수용 기준**
수정 모드에서 텍스트 편집 영역이 표시되고 저장 후 블록 내용이 변경되어야 한다.

**우선순위**
중

---

### REQ-019 · 수정본 기반 브랜치 생성

사용자는 수정 중인 메시지 블록을 기반으로 새 브랜치를 생성할 수 있어야 한다.

**입력**
브랜치로 저장 버튼 클릭

**결과**
수정본 기반 브랜치 생성

**수용 기준**
원본 대화는 유지되고 수정본을 기준으로 별도 브랜치를 만들 수 있어야 한다.

**우선순위**
중

---

### REQ-020 · 메시지 블록 버전 이동

사용자는 하나의 메시지 블록에 여러 버전이 있을 경우 이전/다음 버전을 확인할 수 있어야 한다.

**입력**
버전 이동 버튼 클릭

**결과**
이전 또는 다음 버전 표시

**수용 기준**
하나의 블록에 여러 버전이 있을 경우 버전 번호와 이동 버튼이 표시되어야 한다.

**우선순위**
중

---

### REQ-021 · 원본 블록 복구

사용자는 정제본으로 교체된 메시지 블록을 이전 버전으로 복구할 수 있어야 한다. 정제 결과 승인 후 되돌리기도 본 기능으로 처리한다.

**입력**
버전 이동 또는 활성 버전 변경

**결과**
블록 현재 내용 복원

**수용 기준**
선택한 이전 버전으로 currentVersionId를 변경할 수 있어야 하며, 버전 이력은 삭제하지 않고 유지되어야 한다.

**우선순위**
중
> 2026-08-20 변경: REQ-014~016의 체크박스 기반 블록 선택·해제·개수 표시는 폐기한다. 메시지 본문 드래그 범위 선택만 제공하며, Context는 다음 질문에 범위 스냅샷으로 전달한다.
