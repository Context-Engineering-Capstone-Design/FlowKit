## 2.2 채팅 관리

### FE-CHAT-001 · 새 채팅 시작

사이드바의 새 채팅 버튼을 눌러 빈 대화를 시작한다.

**화면**
사이드바 새 채팅 버튼, 중앙 채팅 영역

**관련 요구사항**
REQ-004

**관련 BE 기능**
BE-CHAT-001, BE-CHAT-002

**트리거**
사이드바 상단 새 채팅 버튼 클릭

**화면 동작**
새 채팅 생성을 요청하고, 응답으로 받은 채팅과 Main 브랜치 정보로 화면을 다시 구성한다. 선택된 블록을 모두 해제하고 우측 Context 패널을 빈 상태로 되돌리며, 적용 중인 Context 표시도 제거한다. 중앙 메시지 영역을 비우고 입력창에 포커스를 옮긴다.

**표시 데이터**
빈 메시지 영역, 기본 채팅 제목, Main 브랜치만 있는 브랜치 목록

**입력 검증**
없음

**오류 처리**
채팅 생성에 실패하면 오류 배너를 표시하고 기존 화면 상태를 유지한다.

**우선순위**
상

**비고**
이전 채팅에서 선택·적용 중이던 Context 상태는 화면에만 있던 값이므로 별도 저장 없이 초기화한다.

---

### FE-CHAT-002 · 최근 대화 목록 표시

사이드바에 사용자의 최근 대화 제목을 목록으로 표시한다.

**화면**
사이드바 '최근 대화' 영역

**관련 요구사항**
REQ-005

**관련 BE 기능**
BE-CHAT-003

**트리거**
앱 로드, 새 채팅 생성, 채팅 제목 변경

**화면 동작**
최근 대화 목록을 조회해 제목을 세로 목록으로 표시한다. 현재 열려 있는 채팅 항목은 활성 상태로 강조한다. 목록이 길어지면 스크롤로 탐색하고, 다음 페이지가 있으면 스크롤 끝에서 이어서 불러온다.

**표시 데이터**
채팅 제목 목록, 현재 채팅 활성 표시

**입력 검증**
없음

**오류 처리**
조회 실패 시 목록 영역에 다시 시도 안내를 표시한다. 대화가 하나도 없으면 빈 상태 안내를 표시한다.

**우선순위**
상

**비고**
정렬 기준(최근 활동 시각)은 서버가 계산하며 화면에는 시각을 표시하지 않는다.

---

### FE-CHAT-003 · 대화 열기

최근 대화 항목을 클릭해 해당 대화를 중앙 영역에 표시한다.

**화면**
사이드바 최근 대화 항목, 중앙 채팅 영역, 헤더 제목

**관련 요구사항**
REQ-005

**관련 BE 기능**
BE-CHAT-005

**트리거**
최근 대화 항목 클릭

**화면 동작**
선택한 채팅의 상세 정보를 조회해 중앙 메시지 영역을 해당 대화 내용으로 교체하고, 헤더에 채팅 제목을 표시한다. 사이드바의 활성 항목을 옮기고, 브랜치 목록을 해당 채팅의 브랜치로 갱신한다. 이전 채팅에서 선택했던 블록과 적용 중이던 Context는 해제한다.

**표시 데이터**
채팅 제목, 메시지 블록 목록, 브랜치 목록

**입력 검증**
없음

**오류 처리**
조회 실패 시 오류 배너를 표시하고 이전 화면을 유지한다. 접근 권한이 없는 채팅이면 목록에서 해당 항목을 제거한다.

**우선순위**
상

**비고**
브랜치를 지정하지 않으면 Main 브랜치가 열린다.

### FE-CHAT-004 · 대화 검색

검색창에 키워드를 입력해 최근 대화 목록을 좁힌다.

**화면**
사이드바 검색창

**관련 요구사항**
REQ-006

**관련 BE 기능**
BE-CHAT-006

**트리거**
검색창에 텍스트 입력

**화면 동작**
입력이 멈춘 뒤 짧은 간격을 두고 검색을 요청해, 제목이 일치하는 대화만 목록에 표시한다. 검색어를 지우면 전체 최근 대화 목록으로 되돌린다.

**표시 데이터**
검색 결과 채팅 제목 목록

**입력 검증**
검색어 앞뒤 공백 제거, 빈 검색어는 전체 목록으로 처리

**오류 처리**
검색 실패 시 목록 영역에 안내를 표시한다. 결과가 없으면 '검색 결과 없음' 안내를 표시한다.

**우선순위**
중

**비고**
입력할 때마다 요청을 보내지 않고 짧게 묶어서 보낸다.

---

### FE-CHAT-005 · 채팅 제목 갱신 반영

첫 질문을 보낸 뒤 생성된 채팅 제목을 화면에 반영한다.

**화면**
헤더 제목, 사이드바 최근 대화 항목

**관련 요구사항**
REQ-005

**관련 BE 기능**
BE-CHAT-004

**트리거**
채팅 제목 생성 완료 응답 수신

**화면 동작**
서버가 확정한 제목으로 헤더 제목과 사이드바 목록의 해당 항목 제목을 함께 갱신한다.

**표시 데이터**
갱신된 채팅 제목

**입력 검증**
없음

**오류 처리**
제목 생성이 실패하면 기본 제목을 그대로 유지한다.

**우선순위**
상

**비고**
제목 문구는 서버·AI가 만들고 화면은 표시만 담당한다.

---

### FE-CHAT-006 · 대화 삭제

최근 대화 항목에서 대화를 삭제한다.

**화면**
사이드바 최근 대화 항목 삭제 버튼, 확인 창

**관련 요구사항**
REQ-066, REQ-065, REQ-064

**관련 BE 기능**
BE-CHAT-009

**트리거**
최근 대화 항목의 삭제 버튼 클릭

**화면 동작**
되돌릴 수 없다는 안내와 함께 확인을 받는다. 취소를 누르면 아무 것도 바꾸지 않는다. 확인하면 삭제를 요청하고, 성공하면 목록에서 해당 항목을 빼며 완료 알림을 표시한다. 지금 열려 있는 대화를 지웠으면 새 빈 대화를 연다.

**표시 데이터**
삭제 버튼, 확인 문구, 대상 대화 제목

**입력 검증**
없음

**오류 처리**
삭제 실패 시 오류 배너를 표시하고 목록과 현재 화면을 유지한다. 이미 없거나 권한이 없는 대화면 목록에서 해당 항목을 제거한다.

**우선순위**
중

**비고**
삭제 버튼은 대화 제목을 가리지 않도록 항목 오른쪽에 둔다. 확인 창은 앱 공통 확인 UI를 쓴다.
