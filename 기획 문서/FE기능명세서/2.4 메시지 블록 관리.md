## 2.4 메시지 블록 관리

### FE-MSG-001 · 메시지 블록 표시

중앙 채팅 영역에 사용자 질문과 AI 응답을 블록 단위로 표시한다.

화면 | 중앙 채팅 영역
관련 요구사항 | REQ-013
관련 BE 기능 | BE-MSG-002

트리거 | 채팅 열기, 브랜치 전환, 새 메시지 생성
화면 동작 | 메시지 블록을 서버가 준 순서대로 나열한다. 각 블록에는 역할 배지(User·AI), 작성 시각, 본문을 표시하고, 본문의 서식(굵게, 목록, 코드 등)을 반영해 그린다. 블록 왼쪽에는 선택용 체크박스를, 오른쪽에는 동작 버튼 묶음을 둔다.
표시 데이터 | 역할 배지, 작성 시각, 본문, 선택 체크박스, 동작 버튼

입력 검증 | 없음
오류 처리 | 목록 조회 실패 시 오류 배너를 표시한다. 메시지가 없으면 빈 상태 안내를 표시한다.
우선순위 | 상

비고 | 본문은 서버가 저장한 현재 활성 버전 내용을 표시한다.

### FE-MSG-002 · 메시지 블록 선택

필요한 메시지 블록을 골라 Context 대상으로 지정한다.

화면 | 메시지 블록 체크박스, 블록 동작 버튼, 우측 Context 패널
관련 요구사항 | REQ-014
관련 BE 기능 | BE-MSG-003

트리거 | 블록 체크박스 클릭, 블록의 'Context에 추가' 버튼 클릭
화면 동작 | 선택한 블록을 강조 표시(배경색·좌측 테두리)하고 체크박스를 켠 상태로 맞춘다. 선택 목록을 우측 Context 패널에 반영하고, 패널이 닫혀 있으면 자동으로 연다.
표시 데이터 | 블록 강조 표시, 체크박스 상태

입력 검증 | 없음
오류 처리 | 없음
우선순위 | 상

비고 | 선택 상태는 화면에만 두고 서버에 저장하지 않는다. 정제·적용·브랜치 생성을 실행하는 시점에 서버가 유효성을 검증한다.

### FE-MSG-003 · 선택 블록 해제

선택한 블록을 다시 해제한다.

화면 | 메시지 블록 체크박스, 우측 Context 패널 목록
관련 요구사항 | REQ-015
관련 BE 기능 | 없음(화면 상태)

트리거 | 체크박스 재클릭, Context 패널 목록의 제거 버튼 클릭
화면 동작 | 해당 블록의 강조 표시와 체크 상태를 해제하고 우측 패널 목록에서도 항목을 제거한다. 선택이 모두 사라지면 패널을 빈 상태로 되돌린다.
표시 데이터 | 해제된 블록의 기본 표시 상태

입력 검증 | 없음
오류 처리 | 없음
우선순위 | 상

### FE-MSG-004 · 선택 블록 수 표시

현재 선택한 블록 개수를 화면에 표시한다.

화면 | 헤더 선택 배지, 우측 Context 패널 선택 수
관련 요구사항 | REQ-016
관련 BE 기능 | 없음(화면 상태)

트리거 | 블록 선택 또는 해제

표시 데이터 | 선택 개수 숫자

입력 검증 | 없음
오류 처리 | 없음
우선순위 | 중

### FE-MSG-005 · 메시지 블록 복사

블록 본문 텍스트를 클립보드로 복사한다.

화면 | 블록 하단 복사 버튼, 블록 더보기 메뉴
관련 요구사항 | REQ-017
관련 BE 기능 | 없음(화면 상태)

트리거 | 복사 버튼 클릭, 더보기 메뉴의 '텍스트 복사' 클릭
화면 동작 | 블록 본문을 서식 없는 텍스트로 클립보드에 복사하고 완료 토스트를 표시한다.
표시 데이터 | 복사 완료 토스트

입력 검증 | 없음
오류 처리 | 클립보드 접근이 거부되면 실패 안내 토스트를 표시한다.
우선순위 | 하

### FE-MSG-006 · 메시지 블록 수정

기존 메시지 블록의 내용을 직접 고친다.

화면 | 블록 수정 모드
관련 요구사항 | REQ-018
관련 BE 기능 | BE-MSG-004

트리거 | 수정 버튼 클릭, 더보기 메뉴의 '직접 수정' 클릭
화면 동작 | 블록 본문을 편집 가능한 텍스트 영역으로 바꾸고 현재 내용을 채운 뒤 커서를 옮긴다. 아래에 '취소', '브랜치로 저장', '저장' 버튼을 표시한다. 저장을 누르면 수정 내용을 서버에 보내 새 버전으로 저장하고, 응답받은 내용으로 본문을 다시 그린 뒤 편집 모드를 닫는다. 취소를 누르면 수정 전 내용으로 되돌린다.
표시 데이터 | 편집 텍스트 영역, 취소·브랜치로 저장·저장 버튼

입력 검증 | 내용 빈 값 확인
오류 처리 | 저장 실패 시 오류 배너를 표시하고 편집 모드와 입력 내용을 유지한다.
우선순위 | 중

비고 | 한 번에 한 블록만 편집한다. 다른 블록 수정을 시작하면 이전 편집은 취소한다. 수정해도 원본 내용은 버전 이력으로 남는다.

### FE-MSG-007 · 수정본 기반 브랜치 생성

수정 중인 내용을 원본에 반영하지 않고 새 브랜치로 저장한다.

화면 | 블록 수정 모드의 '브랜치로 저장' 버튼, 브랜치 생성 모달
관련 요구사항 | REQ-019
관련 BE 기능 | BE-BRANCH-003, BE-BRANCH-004

트리거 | 수정 모드의 '브랜치로 저장' 버튼 클릭
화면 동작 | 수정 중인 내용을 유지한 채 브랜치 생성 모달을 열고, 해당 블록을 분기 지점으로 미리 선택한다. 브랜치 생성이 끝나면 원본 블록은 수정 전 내용으로 되돌리고 편집 모드를 닫는다.
표시 데이터 | 브랜치 생성 모달, 선택된 분기 지점

입력 검증 | 수정 내용 빈 값 확인
오류 처리 | 브랜치 생성이 실패하면 편집 모드와 수정 내용을 유지한다.
우선순위 | 중

비고 | 원본 대화 흐름은 그대로 보존된다.

### FE-MSG-008 · 여기서 브랜치 생성

화면 | 블록 더보기 메뉴, 브랜치 생성 모달
관련 요구사항 | REQ-019

화면 동작 | 브랜치 생성 모달을 열고 분기 지점을 해당 블록으로 미리 선택한다.
표시 데이터 | 브랜치 생성 모달, 선택된 분기 지점

입력 검증 | 없음
오류 처리 | 없음
우선순위 | 중

### FE-MSG-009 · 메시지 블록 버전 이동

한 블록에 여러 버전이 있을 때 이전·다음 버전을 확인한다.

화면 | 블록 하단 버전 이동 영역
관련 요구사항 | REQ-020
관련 BE 기능 | BE-MSG-005, BE-MSG-006

트리거 | 버전 이동 버튼(이전·다음) 클릭
화면 동작 | 버전이 2개 이상인 블록에만 현재 위치와 전체 개수(예: 2/3)를 표시하고 이동 버튼을 노출한다. 버튼을 누르면 해당 버전 내용으로 본문을 바꾸고 위치 표시를 갱신한다. 첫 버전에서는 이전 버튼을, 마지막 버전에서는 다음 버튼을 비활성화한다.
표시 데이터 | 현재 버전 위치·전체 개수, 이전·다음 버튼, 해당 버전 본문

입력 검증 | 없음
오류 처리 | 버전 목록 조회 실패 시 버전 이동 영역을 표시하지 않는다.
우선순위 | 중

### FE-MSG-010 · 활성 버전 변경

선택한 이전 버전을 블록의 현재 내용으로 되돌린다.

화면 | 블록 버전 이동 영역
관련 요구사항 | REQ-021, REQ-034
관련 BE 기능 | BE-MSG-006

트리거 | 이동한 버전을 현재 버전으로 적용하는 동작
화면 동작 | 선택한 버전을 활성 버전으로 지정해달라고 서버에 요청하고, 성공하면 해당 내용을 블록의 현재 내용으로 표시한다. 버전 이력은 그대로 두고 목록에서도 지우지 않는다.
표시 데이터 | 활성 버전으로 바뀐 본문, 갱신된 버전 위치 표시

입력 검증 | 없음
오류 처리 | 변경 실패 시 오류 배너를 표시하고 이전 활성 버전을 유지한다.
우선순위 | 중

비고 | 정제 결과를 승인한 뒤 되돌리고 싶을 때도 이 기능을 사용한다. 별도의 정제 승인 취소 화면은 제공하지 않는다.
