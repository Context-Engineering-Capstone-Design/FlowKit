## 2.5 Context 편집

이 영역은 대부분 화면 상태로 처리되며, 서버는 정제를 실행하는 시점에만 관여한다.

### FE-CTXEDIT-001 · Context 편집 패널 열기·닫기

우측 Context 편집 패널을 열거나 닫는다.

**화면**
우측 Context 편집 패널, 헤더 패널 토글 버튼

**관련 요구사항**
REQ-022

**관련 BE 기능**
BE-CTXEDIT-001

**트리거**
헤더의 패널 토글 버튼 클릭, 패널 상단 닫기 버튼 클릭

**화면 동작**
패널을 보이거나 감추고, 헤더 토글 버튼의 활성 표시를 함께 바꾼다. 패널이 열려 있을 때만 좌우 너비 조절 손잡이를 표시한다.

**표시 데이터**
패널 표시 상태, 토글 버튼 활성 표시

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
상

**비고**
열림·닫힘 상태는 화면에만 두고 서버에 저장하지 않는다. 블록을 선택하면 패널이 닫혀 있어도 자동으로 열린다.

---

### FE-CTXEDIT-002 · 선택된 블록 목록 표시

패널에서 현재 선택한 블록을 목록으로 확인한다.

**화면**
Context 패널 '선택된 블록' 영역

**관련 요구사항**
REQ-023

**관련 BE 기능**
없음(화면 상태)

**트리거**
블록 선택 또는 해제

**화면 동작**
선택된 블록이 없으면 '블록을 선택하면 Context 편집이 시작된다'는 안내를 표시한다. 선택된 블록이 있으면 안내를 감추고, 각 블록을 역할 구분 점, 미리보기 텍스트, 제거 버튼으로 구성한 항목으로 나열한다. 목록 위에는 선택 개수를 표시한다.

**표시 데이터**
선택 개수, 역할 구분 점, 블록 미리보기 텍스트, 제거 버튼

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
상

**비고**
제거 버튼을 누르면 중앙 채팅 영역의 해당 블록 선택도 함께 해제된다. 패널 안 섹션은 배경색·테두리 박스 없이 섹션 이름과 여백으로만 구분한다.

---

### FE-CTXEDIT-004 · 자연어 편집 지시 입력

선택한 블록을 어떻게 정리할지 자연어로 적는다.

**화면**
Context 패널 'AI 편집 지시' 입력창

**관련 요구사항**
REQ-025

**관련 BE 기능**
BE-CTXEDIT-002

**트리거**
입력창에 텍스트 입력

**화면 동작**
입력한 지시문을 화면 상태로 보관하고, 블록별 정제를 실행할 때 함께 전달한다. 입력 내용은 패널을 닫거나 다시 열어도 유지되며, 채팅·브랜치를 바꾸면 초기화한다.

**표시 데이터**
지시문 입력 내용, 안내 문구

**입력 검증**
앞뒤 공백 제거, 빈 값 확인, 길이 제한 확인

**오류 처리**
지시문이 비어 있거나 길이를 넘기면 정제를 실행하지 않고 입력창 아래에 안내를 표시한다. 서버 검증에서 거절되면 반환된 사유를 같은 위치에 표시하고 입력 내용은 유지한다.

**우선순위**
상

**비고**
지시문은 별도로 저장하지 않고 정제 실행 요청에 실어 보낸다.

---

### FE-CTXEDIT-005 · AI 편집 지시 바로 시작

특정 블록의 메뉴에서 곧바로 Context 편집을 시작한다.

**화면**
블록 더보기 메뉴, Context 패널

**관련 요구사항**
REQ-025

**관련 BE 기능**
없음(화면 상태)

**트리거**
AI 응답 블록 더보기 메뉴의 'AI 편집 지시' 클릭

**화면 동작**
해당 블록이 선택되어 있지 않으면 선택 상태로 만들고, Context 패널이 닫혀 있으면 열어 AI 편집 지시 입력창으로 포커스를 옮긴다.

**표시 데이터**
선택된 블록 목록, 편집 지시 입력창 포커스

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
중
