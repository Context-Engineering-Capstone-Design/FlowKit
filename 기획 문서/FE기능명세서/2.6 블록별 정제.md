## 2.6 블록별 정제

정제 결과는 `대기(pending)`, `승인됨(approved)`, `거절됨(rejected)` 세 상태를 가진다. 승인과 거절은 대기 상태에서만 할 수 있고, 한 번 정해진 상태는 이 화면에서 되돌리지 않는다. 승인 후 이전 내용으로 돌아가려면 블록 버전 이동(2.4)을 사용한다.

### FE-REFINE-001 · 블록별 정제 실행

선택한 블록들을 편집 지시에 따라 하나씩 정제한다.

**화면**
Context 패널 '블록별로 정제하기' 버튼

**관련 요구사항**
REQ-028

**관련 BE 기능**
BE-REFINE-001, BE-REFINE-002, BE-REFINE-003

**트리거**
'블록별로 정제하기' 버튼 클릭

**화면 동작**
선택한 블록 목록과 편집 지시를 서버로 보내 정제를 요청한다. 요청 중에는 정제 미리보기 영역에 진행 표시를 띄우고 버튼을 비활성화한다. 결과를 받으면 블록마다 하나씩 대응하는 정제 결과를 만들어 미리보기 목록과 인라인 표시에 반영한다.

**표시 데이터**
진행 표시, 정제 결과 목록, 완료 알림

**입력 검증**
선택된 블록 1개 이상 확인, 편집 지시 빈 값·길이 확인

**오류 처리**
선택된 블록이 없으면 '정제할 블록을 먼저 선택해달라'는 안내를 표시하고 요청하지 않는다. 서버·AI 요청이 실패하면 미리보기 영역에 실패 안내와 다시 시도 버튼을 표시한다.

**우선순위**
상

**비고**
정제 기준이 되는 블록 내용은 서버가 실행 시점에 고정하므로, 요청 이후 블록 내용이 바뀌어도 정제 결과는 요청 시점 기준이다.

---

### FE-REFINE-002 · 원본·정제본 비교 표시

각 블록의 원본과 정제 결과를 패널에서 나란히 확인한다.

**화면**
Context 패널 '블록별 정제 미리보기' 영역

**관련 요구사항**
REQ-029, REQ-032

**관련 BE 기능**
BE-REFINE-004

**트리거**
정제 결과 수신, 정제 결과 상태 변경

**화면 동작**
결과마다 항목을 만들어 블록 식별값, 역할 배지(User·AI), 상태 배지(대기·거절됨)를 위에 표시하고, 그 아래에 '원본'과 '정제 결과'를 위아래로 나눠 미리보기 텍스트로 보여준다. 텍스트가 길면 일정 길이에서 줄이고 말줄임을 붙인다. 각 항목에는 '승인', '거절', '원본 위치' 버튼을 둔다.

**표시 데이터**
블록 식별값, 역할 배지, 상태 배지, 원본·정제 결과 미리보기, 동작 버튼

**입력 검증**
없음

**오류 처리**
결과 조회 실패 시 미리보기 영역에 안내를 표시한다.

**우선순위**
상

**비고**
승인된 항목은 목록에서 제거되므로 미리보기에는 대기·거절 상태만 남는다.

---

### FE-REFINE-003 · 정제본 인라인 표시

정제 결과를 원래 채팅 블록 자리에서 바로 확인한다.

**화면**
중앙 채팅 영역의 정제 대상 블록

**관련 요구사항**
REQ-030

**관련 BE 기능**
BE-REFINE-004

**트리거**
정제 결과 수신

**화면 동작**
정제 대상 블록의 본문을 정제본으로 바꿔 표시하고, 미리보기 중임을 알 수 있게 본문에 구분 표시를 준다. 블록 좌측 테두리를 상태별 색으로 구분한다(대기·거절). 본문 아래에 정제 전용 툴바를 넣고, 결과가 준비되면 첫 번째 대상 블록으로 스크롤한다.

**표시 데이터**
정제본 본문, 미리보기 구분 표시, 상태별 좌측 테두리, 정제 툴바

**입력 검증**
없음

**오류 처리**
대상 블록을 화면에서 찾지 못하면 해당 블록의 인라인 표시를 건너뛰고 패널 목록에는 그대로 표시한다.

**우선순위**
상

**비고**
인라인 표시는 미리보기일 뿐이며, 승인 전까지 블록의 실제 내용은 바뀌지 않는다.

---

### FE-REFINE-004 · 원본·정제본 토글

블록 안에서 원본과 정제본을 번갈아 보며 비교한다.

**화면**
블록 정제 툴바의 '정제'·'원본' 토글

**관련 요구사항**
REQ-031

**관련 BE 기능**
없음(화면 상태)

**트리거**
툴바의 '정제' 또는 '원본' 버튼 클릭

**화면 동작**
'정제'를 누르면 정제본을, '원본'을 누르면 원래 내용을 본문에 표시하고, 누른 버튼을 활성 상태로 표시한다. 처음에는 정제본을 기본으로 보여준다. 어느 쪽을 보고 있는지는 블록별로 따로 기억한다.

**표시 데이터**
선택된 토글 상태, 해당 내용 본문

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
상

**비고**
토글은 보기 방식만 바꾸며 승인·거절 상태에는 영향을 주지 않는다.

---

### FE-REFINE-005 · 정제 결과 승인

정제 결과를 승인해 해당 블록에 즉시 반영한다.

**화면**
블록 정제 툴바 승인 버튼, Context 패널 항목 승인 버튼

**관련 요구사항**
REQ-033, REQ-036, REQ-039, REQ-040, REQ-041, REQ-042

**관련 BE 기능**
BE-REFINE-005

**트리거**
인라인 툴바 또는 패널 항목의 '승인' 버튼 클릭

**화면 동작**
승인을 서버에 요청하고, 성공하면 해당 블록의 본문을 정제본으로 확정 표시한다. 블록에 잠시 적용 완료 효과를 주고, 인라인 정제 툴바를 제거하며, 버전 이동 표시를 갱신한다. 패널 목록에서는 해당 항목을 오른쪽으로 밀리며 접히는 효과와 함께 제거한다. 마지막 항목이 사라지면 정제 미리보기 영역 전체를 서서히 닫는다.

**표시 데이터**
확정된 정제본 본문, 적용 완료 효과, 갱신된 버전 표시

**입력 검증**
대기 상태인지 확인

**오류 처리**
승인 실패 시 오류 배너를 표시하고 항목을 대기 상태로 되돌린다. 이미 처리된 결과라는 응답을 받으면 최신 상태를 다시 조회해 화면을 맞춘다.

**우선순위**
상

**비고**
승인 즉시 반영되며 별도의 '원본에 적용' 단계는 없다. 승인 뒤에는 승인 취소 버튼을 제공하지 않는다. 되돌리려면 블록 버전 이동(FE-MSG-009, FE-MSG-010)을 사용한다. 원본 내용은 버전 이력에 그대로 남는다.

---

### FE-REFINE-006 · 정제 결과 거절

정제 결과를 원본에 반영하지 않도록 거절한다.

**화면**
블록 정제 툴바 거절 버튼, Context 패널 항목 거절 버튼

**관련 요구사항**
REQ-035, REQ-036

**관련 BE 기능**
BE-REFINE-006

**트리거**
인라인 툴바 또는 패널 항목의 '거절' 버튼 클릭

**화면 동작**
거절을 서버에 요청하고, 성공하면 해당 항목의 상태 배지를 '거절됨'으로 바꾸고 블록 좌측 테두리를 거절 상태 색으로 표시한다. 블록 본문은 원본 내용을 유지한다.

**표시 데이터**
거절됨 상태 배지, 거절 상태 좌측 테두리

**입력 검증**
대기 상태인지 확인

**오류 처리**
거절 실패 시 오류 배너를 표시하고 항목을 대기 상태로 되돌린다.

**우선순위**
상

**비고**
거절해도 블록의 현재 내용과 버전은 바뀌지 않는다.

---

### FE-REFINE-007 · 전체 승인

대기 중인 정제 결과를 한 번에 모두 승인한다.

**화면**
Context 패널 '전체 승인' 버튼

**관련 요구사항**
REQ-037, REQ-039

**관련 BE 기능**
BE-REFINE-007

**트리거**
'전체 승인' 버튼 클릭

**화면 동작**
대기 상태인 결과를 한 번에 승인해달라고 서버에 요청한다. 성공한 결과들의 블록 본문을 정제본으로 확정 표시하고 인라인 툴바를 제거한다. 패널 목록의 항목들을 짧은 간격을 두고 차례로 밀어내며 사라지게 한 뒤, 모두 사라지면 정제 미리보기 영역 전체를 닫는다.

**표시 데이터**
순차 제거 효과, 확정된 정제본 본문

**입력 검증**
대기 항목이 1개 이상인지 확인

**오류 처리**
일부만 성공하면 성공한 항목만 반영하고, 실패한 항목은 목록에 남긴 채 오류 배너로 알린다.

**우선순위**
중

**비고**
대기 상태인 결과만 대상으로 하며 이미 거절한 결과는 승인하지 않는다.

---

### FE-REFINE-009 · 미승인 블록 원본 복원

승인하지 않은 블록은 정제 미리보기가 끝나도 원본 내용으로 되돌린다.

**화면**
중앙 채팅 영역, Context 패널 정제 미리보기 영역

**관련 요구사항**
REQ-043

**관련 BE 기능**
BE-REFINE-010

**트리거**
정제 미리보기 종료(전체 승인 후 닫힘, 패널 닫기, 새 정제 실행, 브랜치·채팅 전환)

**화면 동작**
대기·거절 상태로 남은 블록의 본문을 원본 내용으로 되돌리고, 인라인 정제 툴바와 상태별 좌측 테두리 표시를 모두 제거한다. 화면에 남아 있던 정제 결과 정보도 함께 비운다.

**표시 데이터**
원본 본문, 정제 표시가 제거된 기본 블록

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
상

**비고**
승인된 블록은 정제본이 이미 확정 저장된 상태이므로 복원 대상이 아니다.
