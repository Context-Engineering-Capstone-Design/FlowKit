## 2.8 AI 응답 관리

### FE-AIRESP-001 · AI 응답 생성 표시

메시지를 보낸 뒤 AI 응답이 만들어지는 과정을 화면에 보여준다.

**화면**
중앙 채팅 영역

**관련 요구사항**
REQ-013

**관련 BE 기능**
BE-AIRESP-001, BE-AIRESP-002

**트리거**
메시지 전송

**화면 동작**
보낸 질문을 사용자 블록으로 먼저 추가하고, 바로 아래에 AI 블록을 '생성 중' 표시와 함께 만든다. 메시지 영역을 아래로 스크롤해 새 블록이 보이게 한다. 응답을 받으면 생성 중 표시를 실제 답변 내용으로 바꾸고, 서식을 반영해 그린다.

**표시 데이터**
사용자 질문 블록, 생성 중 표시, AI 응답 블록

**입력 검증**
없음

**오류 처리**
생성 실패 응답을 받으면 해당 블록에 실패 안내와 다시 시도 버튼을 표시하고 오류 배너로 원인을 알린다.

**우선순위**
상

**비고**
응답 내용 생성은 서버·AI가 담당하고 화면은 진행 상태와 결과 표시만 맡는다. 여기서 말하는 '생성 중' 표시와 이후 결과 반영은 답변이 한 번에 도착하는 것을 전제로 한 설명이다. 실제 화면은 글자가 만들어지는 대로 흘러 보이는 방식(FE-AIRESP-005)을 따른다.

---

### FE-AIRESP-002 · AI 답변 재생성

같은 질문에 대한 답변을 다시 만든다.

**화면**
AI 블록의 '답변 다시 시도' 버튼, 블록 더보기 메뉴

**관련 요구사항**
REQ-049

**관련 BE 기능**
BE-AIRESP-003

**트리거**
'답변 다시 시도' 버튼 클릭, 더보기 메뉴의 '답변 다시 시도' 클릭

**화면 동작**
해당 블록 본문을 '다시 생성 중' 표시로 바꾸고 버튼을 비활성화한다. 새 답변을 받으면 본문을 그 내용으로 바꾸고, 같은 블록의 새 버전으로 추가해 버전 이동 표시를 갱신한다.

**표시 데이터**
다시 생성 중 표시, 새 답변 본문, 갱신된 버전 표시

**입력 검증**
없음

**오류 처리**
재생성 실패 시 이전 답변 내용을 그대로 되돌리고 오류 배너로 원인을 알린다.

**우선순위**
중

**비고**
새 블록을 만들지 않고 기존 AI 블록의 버전으로 쌓인다. 재생성 후에는 가장 최신 버전을 보여준다.

---

### FE-AIRESP-003 · AI 답변 버전 이동

재생성으로 여러 개가 된 답변의 이전·다음 버전을 확인한다.

**화면**
AI 블록 하단 버전 이동 영역

**관련 요구사항**
REQ-050

**관련 BE 기능**
BE-MSG-005, BE-MSG-006

**트리거**
버전 이동 버튼 클릭

**화면 동작**
버전이 2개 이상일 때만 현재 위치와 전체 개수를 표시하고 이동 버튼을 노출한다. 버튼을 누르면 해당 버전 답변으로 본문을 바꾸고 위치 표시를 갱신하며, 양 끝 버전에서는 해당 방향 버튼을 비활성화한다.

**표시 데이터**
현재 버전 위치·전체 개수, 이전·다음 버튼, 해당 버전 답변

**입력 검증**
없음

**오류 처리**
버전 조회 실패 시 버전 이동 영역을 표시하지 않는다.

**우선순위**
중

**비고**
동작 방식은 메시지 블록 버전 이동(FE-MSG-009)과 같다.

---

### FE-AIRESP-004 · AI 응답 평가

AI 응답에 좋아요 또는 싫어요를 남긴다.

**화면**
AI 블록 하단 좋아요·싫어요 버튼

**관련 요구사항**
REQ-051

**관련 BE 기능**
BE-AIRESP-004

**트리거**
좋아요 또는 싫어요 버튼 클릭

**화면 동작**
누른 버튼을 활성 상태로 표시하고 반대쪽 버튼의 활성 표시는 해제한다. 이미 활성인 버튼을 다시 누르면 평가를 해제한다. 바뀐 평가 상태를 서버에 저장한다. 화면을 다시 열어도 저장된 평가 상태가 그대로 표시된다.

**표시 데이터**
좋아요·싫어요 버튼 활성 상태

**입력 검증**
없음

**오류 처리**
저장 실패 시 버튼을 이전 상태로 되돌린다.

**우선순위**
하

**비고**
버튼 표시는 즉시 바꾸고 저장은 뒤이어 처리한다. 평가는 AI 응답 블록에만 제공한다.

### FE-AIRESP-005 · 답변 스트리밍 표시

AI 답변이 다 만들어지기 전부터, 지금까지 생성된 글자를 화면에 흘려 보여준다.

**화면**
중앙 채팅 영역

**관련 요구사항**
REQ-069

**관련 BE 기능**
BE-AIRESP-007, BE-AIRESP-009

**트리거**
메시지 전송, 답변 다시 시도, 실패한 답변 재시도, 대화·브랜치 열기(진행 중인 답변이 있을 때)

**화면 동작**
전송하는 즉시 질문 블록과 빈 답변 블록을 올린다. 답변 블록의 통로에 붙어 도착하는 글자를 본문 뒤에 이어 붙인다. 첫 글자가 오기 전까지는 '생각하는 중' 표시를 보여준다. 아직 안 닫힌 마크다운 문법(코드 울타리 등)은 임시로 닫아서 그려 깨짐을 막는다. 사용자가 위로 스크롤하면 자동으로 따라 내려가지 않고 '맨 아래로' 버튼을 보여준다. 대화나 브랜치를 열 때 아직 만들어지는 중인 답변이 있으면 자동으로 통로에 다시 붙는다.

**표시 데이터**
흘러 들어오는 답변 글자, 생각하는 중 표시, 맨 아래로 버튼

**입력 검증**
없음

**오류 처리**
연결이 끊기면 몇 번 다시 붙어보고, 안 되면 새로고침 안내로 넘긴다. 생성이 실패로 끝나면 오류 배너로 알린다.

**우선순위**
상

**비고**
인증 정보를 실어야 해서 EventSource가 아니라 fetch로 직접 스트림을 읽는다. 재생성·실패 재시도도 같은 방식으로 동작한다.

### FE-AIRESP-006 · 답변 생성 중단

답변이 만들어지는 도중에 생성을 멈춘다.

**화면**
입력창의 전송 버튼 자리(생성 중에는 중단 버튼으로 바뀜)

**관련 요구사항**
REQ-070

**관련 BE 기능**
BE-AIRESP-008

**트리거**
중단 버튼 클릭

**화면 동작**
생성 중에는 전송 버튼 자리에 중단 버튼을 둔다. 누르면 그 시점까지 흘러 들어온 본문을 그대로 두고 '중단됨' 표시를 붙인다. 중단된 블록은 체크박스를 붙이지 않아 Context로 고를 수 없고, 정제 대상·브랜치 분기점 목록에도 나오지 않는다.

**표시 데이터**
중단됨 표시

**입력 검증**
없음

**오류 처리**
중단 요청이 실패하면 오류 배너로 알리고 버튼을 원래대로 되돌린다.

**우선순위**
중

**비고**
화면에서 막는 것은 보조 수단이고, 최종 판단은 서버(BE-AIRESP-008)가 한다.
