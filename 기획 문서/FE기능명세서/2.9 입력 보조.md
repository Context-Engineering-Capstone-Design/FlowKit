## 2.9 입력 보조

MVP에서는 음성 입력을 제공하지 않는다. 입력창의 마이크 버튼과 관련 화면은 구현 범위에서 제외한다.

### FE-INPUT-001 · 파일 첨부

입력창에서 일반 파일을 첨부한다.

**화면**
입력창 첨부 버튼, 첨부 메뉴, 첨부 목록

**관련 요구사항**
REQ-052

**관련 BE 기능**
BE-INPUT-001

**트리거**
첨부 버튼 클릭 후 '파일 업로드' 선택, 파일 선택 완료

**화면 동작**
첨부 버튼을 누르면 '사진 업로드'와 '파일 업로드' 두 항목이 있는 작은 메뉴를 연다. '파일 업로드'를 고르면 파일 선택 창을 열고, 선택한 파일마다 입력창 위 첨부 목록에 항목을 추가한다. 각 항목에는 종류에 맞는 아이콘, 파일명, 확장자, 제거 버튼을 표시한다. 파일은 서버에 올리고 업로드 진행 상태를 항목에 나타낸다.

**표시 데이터**
첨부 항목(아이콘, 파일명, 확장자, 제거 버튼), 업로드 진행 상태

**입력 검증**
확장자·용량 제한 확인

**오류 처리**
허용되지 않는 형식이거나 용량을 넘기면 해당 항목을 추가하지 않고 사유를 안내한다. 업로드가 실패하면 항목에 실패 표시와 다시 시도 버튼을 둔다.

**우선순위**
하

---

### FE-INPUT-002 · 이미지 첨부

입력창에서 이미지를 첨부한다.

**화면**
입력창 첨부 메뉴, 첨부 목록

**관련 요구사항**
REQ-053

**관련 BE 기능**
BE-INPUT-001

**트리거**
첨부 메뉴의 '사진 업로드' 선택, 이미지 선택 완료

**화면 동작**
이미지 파일만 고를 수 있는 선택 창을 열고, 선택한 이미지를 첨부 목록에 이미지 아이콘과 함께 추가한다. 나머지 동작은 파일 첨부와 같다.

**표시 데이터**
이미지 첨부 항목, 업로드 진행 상태

**입력 검증**
이미지 형식·용량 제한 확인

**오류 처리**
파일 첨부와 동일하게 처리한다.

**우선순위**
하

---

### FE-INPUT-003 · 첨부 항목 제거

첨부한 파일이나 이미지를 목록에서 뺀다.

**화면**
첨부 항목의 제거 버튼

**관련 요구사항**
REQ-054

**관련 BE 기능**
BE-INPUT-002

**트리거**
첨부 항목의 제거 버튼 클릭

**화면 동작**
해당 항목을 첨부 목록에서 없앤다. 이미 서버에 올라간 파일이면 정리를 요청하고, 아직 올라가지 않았으면 화면에서만 지운다.

**표시 데이터**
제거된 첨부 목록

**입력 검증**
없음

**오류 처리**
정리 요청이 실패해도 화면 목록에서는 항목을 제거한다.

**우선순위**
하

---

### FE-INPUT-004 · 웹 검색 토글

질문에 웹 검색을 함께 쓸지 켜고 끈다.

**화면**
입력창 하단 웹 검색 버튼

**관련 요구사항**
REQ-055

**관련 BE 기능**
BE-INPUT-004

**트리거**
웹 검색 버튼 클릭

**화면 동작**
버튼의 활성 상태를 전환하고 색으로 켜짐·꺼짐을 구분한다. 바뀐 상태를 알리는 짧은 알림을 표시하고, 메시지를 보낼 때 이 값을 함께 전달한다.

**표시 데이터**
웹 검색 버튼 활성 상태

**입력 검증**
없음

**오류 처리**
선택한 모델이 웹 검색을 지원하지 않는다는 응답을 받으면 버튼을 끄고 사유를 안내한다.

**우선순위**
하

---

### FE-INPUT-005 · 모델 선택

질문에 사용할 AI 모델을 고른다.

**화면**
입력창 하단 모델 선택 버튼, 모델 목록

**관련 요구사항**
REQ-056

**관련 BE 기능**
BE-INPUT-005, BE-INPUT-006

**트리거**
모델 선택 버튼 클릭, 목록에서 모델 선택

**화면 동작**
버튼을 누르면 선택 가능한 모델 목록을 연다. 각 항목에는 구분 색 점, 모델 이름, 한 줄 설명을 표시하고, 특징이 있는 모델에는 태그(예: 최신, 빠름, 추론)를 붙인다. 현재 선택된 모델은 활성 표시한다. 모델을 고르면 목록을 닫고 버튼에 선택한 모델 이름을 표시하며, 메시지를 보낼 때 이 값을 함께 전달한다.

**표시 데이터**
모델 이름, 설명, 특징 태그, 현재 선택 표시

**입력 검증**
없음

**오류 처리**
목록 조회에 실패하면 기본 모델만 표시한다. 사용할 수 없는 모델이라는 응답을 받으면 기본 모델로 되돌리고 사유를 안내한다.

**우선순위**
하

**비고**
모델 목록은 나중에 늘어날 수 있으므로 목록 데이터로 관리한다.

---

### FE-INPUT-006 · 입력창 동작

질문을 입력하고 보내는 기본 동작을 제공한다.

**화면**
입력창, 전송 버튼

**관련 요구사항**
REQ-052, REQ-053, REQ-055, REQ-056

**관련 BE 기능**
BE-INPUT-003, BE-INPUT-004, BE-INPUT-006

**트리거**
입력창 입력, 전송 버튼 클릭, 전송 단축키 입력

**화면 동작**
입력 내용이 길어지면 입력창 높이를 일정 한도까지 자동으로 늘린다. 전송하면 입력 내용과 함께 첨부 목록, 웹 검색 설정, 선택 모델을 같이 보내고, 전송 후 입력창과 첨부 목록을 비운다.

**표시 데이터**
입력 내용, 입력창 높이

**입력 검증**
내용 빈 값 확인(첨부만 있는 경우 전송 허용 여부 포함)

**오류 처리**
전송 실패 시 입력 내용과 첨부 목록을 되살려 다시 보낼 수 있게 한다.

**우선순위**
상

---

### FE-INPUT-007 · 음성 입력(MVP 제외)

MVP에서는 음성 입력을 제공하지 않는다.

**화면**
입력창 하단 마이크 버튼

**관련 요구사항**
REQ-057

**관련 BE 기능**
BE-INPUT-007

**트리거**
없음

**화면 동작**
MVP에서는 마이크 버튼과 음성 입력 화면을 만들지 않는다. 나중에 도입하면 입력창 하단에 마이크 버튼을 두고 음성을 글로 바꿔 입력창에 채우는 방식으로 확장한다.

**표시 데이터**
없음

**입력 검증**
없음

**오류 처리**
없음

**우선순위**
MVP 제외

**비고**
팀 내 범위 공유용 항목이며 개발 대상이 아니다. 프로토타입 화면에는 마이크 버튼이 남아 있으나 구현하지 않는다.
