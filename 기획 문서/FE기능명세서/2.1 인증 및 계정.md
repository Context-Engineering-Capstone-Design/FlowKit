## 2.1 인증 및 계정

### FE-AUTH-001 · 로그인 화면 표시

서비스 접속 시 인증 상태에 따라 로그인 화면 또는 메인 화면을 표시한다.

화면 | 로그인 화면
관련 요구사항 | REQ-001, REQ-002
관련 BE 기능 | BE-AUTH-001

트리거 | 앱 최초 로드
화면 동작 | 인증 상태 확인 결과를 받기 전에는 로딩 상태를 유지한다. 미인증이면 로고·서비스 한 줄 설명·Google 로그인 버튼이 있는 로그인 화면을 표시하고, 인증 상태면 로그인 화면 없이 메인 화면으로 바로 진입한다.
표시 데이터 | FlowKit 로고, 서비스 한 줄 설명, Google 로그인 버튼

입력 검증 | 없음
오류 처리 | 인증 상태 확인 요청이 실패하면 로그인 화면을 기본값으로 표시한다.
우선순위 | 상

### FE-AUTH-002 · Google 로그인 시작

'Google로 계속하기' 버튼 클릭 시 Google SDK로 로그인을 진행하고 서버 인증을 요청한다.

화면 | 로그인 화면
관련 요구사항 | REQ-002
관련 BE 기능 | BE-AUTH-002, BE-AUTH-003, BE-AUTH-004, BE-AUTH-005

트리거 | 'Google로 계속하기' 버튼 클릭
화면 동작 | 버튼을 로딩 상태로 바꿔 중복 클릭을 막고, Google SDK로 사용자 동의를 받아 ID 토큰을 발급받는다. 발급된 ID 토큰을 서버로 전달해 로그인 처리를 요청하고, 인증 토큰을 받으면 로그인 화면을 닫고 메인 화면으로 전환한다.
표시 데이터 | 버튼 로딩 인디케이터

입력 검증 | 없음 (Google SDK가 처리)
오류 처리 | 사용자가 Google 동의 절차를 취소하면 버튼을 원래 상태로 되돌리고 별도 오류 표시 없이 종료한다. 서버 인증이 실패하면 화면 내 안내 영역에 오류 메시지를 표시한다.
우선순위 | 상

비고 | 서버는 Google SDK가 발급한 ID 토큰만 검증하며 OAuth 리다이렉트·콜백 URL 방식은 사용하지 않는다.

### FE-AUTH-003 · 로그인 세션 유지

앱 재방문 시 기존 로그인 상태를 유지하고, 인증 토큰 만료 시 자동으로 재발급받는다.

화면 | 전체 화면 공통
관련 요구사항 | REQ-002
관련 BE 기능 | BE-AUTH-001, BE-AUTH-006

트리거 | 앱 로드, API 요청 중 인증 토큰 만료 응답 수신
화면 동작 | 저장된 인증 토큰으로 로그인 상태를 확인해 로그인 화면 없이 바로 메인 화면을 표시한다. API 요청 중 토큰 만료 응답을 받으면 저장된 재발급 토큰으로 새 인증 토큰을 요청한 뒤 원래 요청을 이어서 처리한다.
표시 데이터 | 없음

입력 검증 | 없음
오류 처리 | 재발급 토큰까지 만료되었거나 무효화된 경우 로그인 화면으로 전환하고 안내 메시지를 표시한다.
우선순위 | 중

### FE-AUTH-004 · 프로필 메뉴

사이드바 하단 아바타를 클릭하면 사용자 정보와 메뉴를 담은 팝업을 연다.

화면 | 사이드바 하단 프로필 영역
관련 요구사항 | REQ-003, REQ-058, REQ-059
관련 BE 기능 | BE-AUTH-007, BE-USERSET-001

트리거 | 사이드바 하단 아바타·이름 영역 클릭
화면 동작 | 팝업을 열어 로그인 사용자의 아바타, 이름, 이메일을 표시하고 '사용자 정보', 'API 키 관리', '피드백 남기기', '로그아웃' 메뉴 항목을 나열한다. 팝업 바깥을 클릭하면 닫는다.
표시 데이터 | 아바타(프로필 이미지 또는 이름 첫 글자), 이름, 이메일

입력 검증 | 없음
오류 처리 | 사용자 정보 조회에 실패하면 팝업에 기본 표시값(이름 미상 등)을 유지한다.
우선순위 | 중

비고 | 'API 키 관리'와 '피드백 남기기' 메뉴가 여는 화면의 상세 동작은 2.10 사용자 설정에서 다룬다.

### FE-AUTH-005 · 사용자 정보 조회 및 수정

프로필 메뉴의 '사용자 정보'를 클릭하면 모달에서 이름·이메일·메모를 확인하고 수정할 수 있다.

화면 | 사용자 정보 모달
관련 요구사항 | REQ-059
관련 BE 기능 | BE-AUTH-008, BE-USERSET-002

트리거 | 프로필 메뉴의 '사용자 정보' 클릭(열림), 저장 버튼 클릭(수정)
화면 동작 | 모달을 열면 현재 이름·이메일·메모 값을 입력 필드에 채운다. 저장 버튼을 누르면 입력값을 서버로 전달해 저장을 요청하고, 성공하면 모달을 닫고 완료 안내를 표시하며 사이드바·프로필 팝업의 이름·이메일 표시를 갱신한다.
표시 데이터 | 이름, 이메일, 메모 입력 필드

입력 검증 | 이메일 형식 확인, 이름 빈 값 확인
오류 처리 | 이메일 형식 오류·이메일 중복 등 서버 오류를 모달 내 안내 영역에 표시하고 입력값은 유지한다.
우선순위 | 중

### FE-AUTH-006 · 로그아웃

프로필 메뉴의 '로그아웃'을 클릭하면 세션을 종료하고 로그인 화면으로 돌아간다.

화면 | 사이드바 프로필 메뉴
관련 요구사항 | REQ-003
관련 BE 기능 | BE-AUTH-009

트리거 | 프로필 메뉴의 '로그아웃' 클릭
화면 동작 | 로그아웃을 서버에 요청하고, 저장된 인증 토큰을 지운 뒤 로그인 화면으로 전환한다.
표시 데이터 | 없음

입력 검증 | 없음
오류 처리 | 서버 요청이 실패해도 클라이언트에 저장된 인증 토큰은 지우고 로그인 화면으로 전환한다.
우선순위 | 중

### FE-AUTH-007 · 인증 오류 안내

서버가 표준 인증 오류를 반환하면 상황에 맞는 안내를 화면에 표시한다.

화면 | 전체 화면 공통(오류 배너)
관련 요구사항 | REQ-001, REQ-002, REQ-003
관련 BE 기능 | BE-AUTH-010

트리거 | API 응답에서 인증 오류 코드 수신(`UNAUTHORIZED`, `TOKEN_EXPIRED`, `SESSION_NOT_FOUND`, `INVALID_GOOGLE_ID_TOKEN` 등)
화면 동작 | 오류 코드별로 사용자 친화적 안내 문구를 오류 배너에 표시한다. `TOKEN_EXPIRED`·`SESSION_NOT_FOUND`는 로그인 화면으로 전환한 뒤 안내하고, 그 외 오류는 현재 화면을 유지한 채 배너만 표시한다.
표시 데이터 | 오류 배너 메시지

입력 검증 | 없음
오류 처리 | 정의되지 않은 오류 코드는 공통 문구("문제가 발생했습니다. 다시 시도해주세요")로 표시한다.
우선순위 | 중
