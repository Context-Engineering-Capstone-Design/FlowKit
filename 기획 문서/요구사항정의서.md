# FlowKit 요구사항정의서

## 1. 요구사항 분류


| 구분         | 설명                                                            |
| ---------- | ------------------------------------------------------------- |
| 인증 및 계정    | 로그인, 로그아웃, 사용자 정보 확인 및 수정                                     |
| 채팅 관리      | 새 채팅 시작, 최근 대화 확인, 대화 검색                                      |
| 브랜치 관리     | 브랜치 목록 확인, 브랜치 전환, 브랜치 생성, 원본 Context 이동                      |
| 메시지 블록 관리  | 메시지 표시, 선택, 해제, 수정, 복사, 버전 이력·복구                              |
| Context 편집 | 선택된 블록 확인, 빠른 편집, 자연어 지시                                      |
| 블록별 정제     | 선택 블록 개별 정제, 원본/정제본 비교, 인라인 토글, 승인 즉시 적용·패널 제거, 전체 승인 시 카드 닫힘 |
| Context 적용 | 정제 Context 미리보기, Context 적용, 적용 상태 표시 및 해제                    |
| AI 응답 관리   | 답변 재생성, 응답 버전 이동, 좋아요/싫어요 표시                                  |
| 입력 보조      | 파일 첨부, 이미지 첨부, 첨부 제거, 웹 검색 토글, 모델 선택, 음성 입력 버튼                |
| 사용자 설정     | 프로필 메뉴, 사용자 정보 관리, API 키 관리, 피드백 제출                           |
| 알림 및 오류    | 토스트 알림, 오류 배너 표시                                              |
