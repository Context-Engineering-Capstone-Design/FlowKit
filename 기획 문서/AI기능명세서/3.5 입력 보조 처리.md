## 3.5 입력 보조 처리

**FE/BE/AI 책임 기준:** 첨부 파일 업로드·검증·저장은 BE-INPUT-001부터 003까지가, 웹 검색 옵션과 모델 선택값 검증은 BE-INPUT-004부터 006까지가 맡는다. AI 모델링 파트는 확정된 옵션과 첨부 내용을 실제 모델 호출에 반영한다. 음성 입력은 MVP 범위가 아니다.

### AI-SEARCH-001 · 웹 검색 도구 연결

웹 검색 모드에 따라 검색 도구를 붙이거나, 붙이지 않거나, 반드시 쓰도록 강제한다.

**도메인**
WebSearch, Answer

**관련 요구사항**
REQ-055

**관련 BE 기능**
BE-INPUT-004, BE-AIRESP-001

**관련 화면**
웹 검색 선택 상자, 메시지 전송 버튼

**입력**
`webSearchMode`(`off` | `auto` | `always`), `resolvedModel`

**처리**
`webSearchMode`가 `off`이면 검색 도구를 붙이지 않는다 — 이 경우 모델은 검색을 쓸 수 없다. `auto`면 도구를 붙이되 실제로 쓸지는 모델이 질문을 보고 스스로 판단한다. `always`면 도구를 붙이고 `tool_choice`로 반드시 쓰도록 강제한다. 어느 경우든 별도 검색 서비스를 부르지 않는다. `off`가 아닌데 고른 모델이 검색을 지원하지 않으면 오류를 낸다.

**출력**
검색 도구 부착 여부(및 강제 여부)가 반영된 모델 클라이언트

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
검색을 지원하지 않는 모델, 검색 도구 연결 실패

**우선순위**
하

**비고**
검색 수행 자체는 모델 쪽에서 일어난다. 검색어를 직접 만들거나 결과를 골라내지 않는다. 선택 상자 표시와 사용 가능 여부 안내는 FE·BE 책임이다. 기본값은 `off`다 — 검색(외부 호출·지연 시간)은 사용자가 명시적으로 선택해야 일어난다.

AI 응답 표시 영역

모델 응답

**처리**

**출력**
`searchSources(title, url)`

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
없음

**우선순위**
하

**비고**
근거를 저장할지, 화면에 어떻게 보여줄지는 BE·FE가 정한다. 근거가 없다고 해서 답변 생성을 실패로 보지 않는다.

**출력**

**상태 변화**
없음

**권한**
없음

**오류**
첨부 입력을 지원하지 않는 모델, 읽을 수 없는 이미지, 지원하지 않는 형식

**우선순위**
하

**비고**

**도메인**
Attachment, Answer

**관련 요구사항**
REQ-052

**관련 BE 기능**
BE-INPUT-003, BE-AIRESP-001

**출력**
첨부 내용이 붙은 질문 메시지

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
글자를 뽑을 수 없는 파일, 지원하지 않는 형식

**우선순위**
하

**비고**
