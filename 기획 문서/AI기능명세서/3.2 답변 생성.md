## 3.2 답변 생성

**FE/BE/AI 책임 기준:** 적용 Context의 유효성 검증과 스냅샷 확정은 BE-CTXAPPLY-001, 002가, 답변 저장은 BE-AIRESP-002가 맡는다. AI 모델링 파트는 백엔드가 확정해 넘긴 입력으로 답변 본문만 만들어 돌려준다.

### AI-ANSWER-001 · 답변 입력 메시지 구성

백엔드가 넘긴 대화 흐름과 새 질문을 모델이 읽는 순서대로 조립한다.

**도메인**
Answer

**관련 요구사항**
REQ-013

**관련 BE 기능**
BE-AIRESP-001

**관련 화면**
메시지 전송 버튼, AI 응답 표시 영역

**입력**
`apiKey`, `userPrompt`, `messageFlow(role, content)`, `appliedContext`, `attachments` 선택값, `webSearchMode` 선택값, `selectedModelId` 선택값

**처리**
기본 지침을 담은 시스템 메시지를 맨 앞에 두고, 대화 흐름을 `user`와 `assistant` 메시지로 순서대로 이어 붙인 뒤, 마지막에 새 질문을 놓는다. 기본 지침은 사용자의 언어로 답할 것, 모르는 것은 지어내지 말 것, 필요하면 마크다운을 쓸 것, 오늘 날짜(호출 시점 기준)를 알릴 것, 답 길이는 질문에 필요한 만큼만 쓸 것, 목록·표·강조는 꼭 필요할 때만 쓸 것을 담는다.

**출력**
모델에 넣을 메시지 목록

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
질문 없음

**우선순위**
상

**비고**
질문이 비어 있으면 모델을 부르지 않고 바로 오류를 낸다.

---

### AI-ANSWER-002 · 적용 Context 우선 반영

사용자가 고른 Context가 있으면 그 내용만 근거로 답하도록 입력을 좁힌다.

**도메인**
Answer, ContextApply

**관련 요구사항**
REQ-046, NFR-011

**관련 BE 기능**
BE-CTXAPPLY-002, BE-AIRESP-001

**관련 화면**
이 Context로 질문하기 버튼, Context pill

**입력**
`appliedContext`

**처리**
적용 Context가 있으면 시스템 메시지 뒤에 Context 안내 문단을 덧붙인다. 안내 문단은 아래 내용만 근거로 답하라는 지시와, "방금", "위 내용" 같은 표현도 이 내용을 가리키는 것으로 읽으라는 지시를 담는다. 공백만 있는 Context 항목은 제외하고, 남는 항목이 없으면 안내 문단을 붙이지 않는다.

**출력**
Context가 반영된 시스템 메시지

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
없음

**우선순위**
상

**비고**
Context 안내를 항상 붙이면 Context 없이 물었을 때도 모델이 "Context가 없다"며 답을 거부한다. 사용자가 블록을 골랐을 때만 붙인다. 적용 Context가 있을 때 이전 대화 흐름을 함께 넣을지는 백엔드가 정해 넘긴다.

### AI-ANSWER-003 · 답변 생성 실행

조립한 입력으로 모델을 불러 답변 본문을 만든다.

**도메인**
Answer

**관련 요구사항**
REQ-013

**관련 BE 기능**
BE-AIRESP-001, BE-AIRESP-002

**관련 화면**
AI 응답 표시 영역

**입력**
조립된 메시지 목록, `apiKey`, `selectedModelId` 선택값, `webSearchMode` 선택값

**처리**
AI-CORE-002로 모델을 정하고 AI-CORE-003으로 클라이언트를 만들어 호출한다. 결과 본문의 앞뒤 공백을 없애 돌려준다. `webSearchMode`가 `off`가 아닌 요청은 AI-SEARCH-001을 함께 적용한다.

**출력**
`answerText`, `searchSources` 선택값

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
질문 없음, 모델 호출 실패, 응답 시간 초과, 응답 본문 없음

**우선순위**
상

**비고**
본문이 비어 있으면 백엔드가 저장을 거부하므로 오류로 올린다. 답변을 메시지 블록과 버전으로 저장하는 것은 BE-AIRESP-002 책임이다.

### AI-ANSWER-004 · 답변 재생성 입력 구성

기존 답변을 다시 만들 때, 그 답변이 처음 만들어졌을 때와 같은 조건으로 입력을 맞춘다.

**도메인**
Answer

**관련 요구사항**
REQ-049, NFR-011

**관련 BE 기능**
BE-AIRESP-003

**관련 화면**
답변 다시 시도 버튼

**입력**
`apiKey`, 원래 답변 생성에 쓰인 입력 스냅샷(`userPrompt`, `messageFlow`, `appliedContext`, `selectedModelId`, `webSearchMode`)

**처리**
백엔드가 넘긴 원래 입력 스냅샷을 그대로 써서 AI-ANSWER-001부터 003까지를 다시 수행한다. 재생성이라는 이유로 Context를 빼거나 대화 흐름을 새로 계산하지 않는다.

**출력**
`answerText`

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
입력 스냅샷 없음, 모델 호출 실패, 응답 시간 초과

**우선순위**
중

**비고**
처음 답변이 적용 Context를 근거로 만들어졌다면 재생성도 같은 Context를 근거로 해야 한다. 조건이 달라지면 사용자는 같은 질문에 대한 두 답변을 버전으로 비교할 수 없다. 입력 스냅샷을 복원해 넘기는 것은 백엔드 책임이다.
