## 2.9 입력 보조

MVP에서는 **음성 인식 기능을 도입하지 않는다**. `BE-INPUT-007`은 팀 내 공유용 명시 항목이며, MVP 개발 범위에 포함되지 않는다.

**FE/BE 책임 기준**

### BE-INPUT-001 · 첨부 파일 업로드 검증 및 임시 저장

사용자가 입력창에서 첨부한 파일 또는 이미지를 서버에서 사용할 수 있도록 업로드하고 검증한다.

**도메인**
InputAssist, Attachment

**관련 요구사항**
REQ-052, REQ-053

**관련 화면**
파일 첨부 버튼, 이미지 첨부 버튼

**입력**
userId, chatId, file, fileName, fileType, fileSize

**처리**
파일 확장자, MIME type, 크기 제한, 사용자 권한을 검증한 뒤 임시 Attachment로 저장한다.

**출력**
attachmentId, fileName, fileType, fileSize, previewUrl 선택값, uploadStatus

**DB 영향**
Attachment 생성, 파일 스토리지 저장

**상태 변화**
없음 → 임시 첨부 생성

**권한**
로그인 필요, 채팅 소유자

**오류**
파일 없음, 허용되지 않은 확장자, 용량 초과, 업로드 실패, 권한 없음

**우선순위**
하

**비고**
파일 chip 표시 자체는 FE 책임. MVP 제외 가능

---

### BE-INPUT-002 · 첨부 항목 제거 및 임시 파일 정리

사용자가 첨부 chip을 제거했을 때 이미 서버에 업로드된 임시 첨부 파일을 정리한다.

**도메인**
InputAssist, Attachment

**관련 요구사항**
REQ-054

**관련 화면**
첨부 chip 제거 버튼

**입력**
userId, chatId, attachmentId

**처리**
첨부 파일 소유권과 사용 여부를 확인하고, 아직 메시지에 연결되지 않은 임시 Attachment를 삭제 또는 만료 처리한다.

**출력**
attachmentId, deleteStatus

**DB 영향**
Attachment 삭제/상태 수정, 파일 스토리지 삭제 가능

**상태 변화**
임시 첨부 → 제거됨/만료됨

**권한**
로그인 필요, 채팅 소유자

**오류**
첨부 없음, 이미 메시지에 연결됨, 삭제 실패, 권한 없음

**우선순위**
하

**비고**
chip 제거 UI는 FE 상태. 서버 업로드 전 제거라면 BE 호출 불필요

---

### BE-INPUT-003 · 메시지 전송 시 첨부 연결

사용자가 첨부 파일이 있는 상태로 메시지를 전송하면 해당 첨부를 사용자 메시지와 연결한다.

**도메인**
InputAssist, MessageBlock, Attachment

**관련 요구사항**
REQ-052, REQ-053

**관련 화면**
메시지 전송 버튼

**입력**
userId, chatId, branchId, userMessageBlockId, attachmentIds

**처리**
첨부 파일이 현재 사용자와 채팅에 속하고, 아직 다른 메시지에 연결되지 않았는지 확인한 뒤 MessageBlock과 연결한다.

**출력**
messageBlockId, attachments(attachmentId, fileName, fileType, fileSize)

**DB 영향**
MessageAttachment 생성, Attachment 수정

**상태 변화**
임시 첨부 → 메시지 첨부 확정

**권한**
로그인 필요, 채팅 소유자

**오류**
첨부 없음, 첨부 소유권 없음, 이미 사용된 첨부, 연결 실패

**우선순위**
하

**비고**
사용자 메시지 생성은 BE-MSG-001에서 처리. 첨부 연결만 담당

---

### BE-INPUT-004 · 웹 검색 모드 검증 및 AI 입력 반영

사용자가 고른 웹 검색 모드(`off`/`auto`/`always`)로 메시지를 전송하면 해당 모드가 사용 가능한지 검증하고 AI 입력에 반영한다.

**도메인**
InputAssist, AIResponse

**관련 요구사항**
REQ-055

**관련 화면**
웹 검색 선택 상자, 메시지 전송 버튼

**입력**
userId, chatId, branchId, webSearchMode(`off` | `auto` | `always`)

**처리**
사용자 권한을 확인한다. `webSearchMode`가 `off`가 아니면 고른 모델이 검색을 지원하는지 확인하고, 지원하지 않으면 오류를 낸다. AI 응답 생성 입력에 webSearchMode 값을 그대로 포함한다.

**출력**
webSearchOption(mode, available, reason 선택값)

**DB 영향**
없음 또는 AIResponseJob 옵션 저장

**상태 변화**
웹 검색 모드 확정

**권한**
로그인 필요

**오류**
지원하지 않는 모델, 권한 없음, 웹 검색 사용 불가

**우선순위**
하

**비고**
선택 상자 UI는 FE 책임. 실제 웹 검색 수행과 `auto`/`always` 판단·강제는 AI 모델링 책임(AI-SEARCH-001).

---

### BE-INPUT-005 · 사용 가능 모델 목록 조회

사용자가 선택할 수 있는 AI 모델 목록을 조회한다.

**도메인**
InputAssist, ModelConfig

**관련 요구사항**
REQ-056

**관련 화면**
모델 선택 버튼, 모델 드롭다운

**입력**
userId 선택값

**처리**
시스템에서 사용 가능한 모델 목록과 사용자 권한에 따른 선택 가능 여부를 조회한다.

**출력**
models(modelId, displayName, provider, isAvailable, isDefault)

**DB 영향**
ModelConfig 조회 가능

**상태 변화**
없음

**권한**
로그인 필요 또는 비로그인 허용 가능

**오류**
모델 목록 없음, 조회 실패

**우선순위**
하

**비고**
MVP에서는 FE 상수로 처리 가능. 모델 목록이 동적으로 바뀌면 BE 관리

---

### BE-INPUT-006 · 메시지 전송 시 모델 선택값 검증

사용자가 선택한 AI 모델로 응답 생성을 요청할 수 있는지 검증한다.

**도메인**
InputAssist, AIResponse

**관련 요구사항**
REQ-056

**관련 화면**
모델 선택 버튼, 메시지 전송 버튼

**입력**
userId, chatId, branchId, selectedModelId

**처리**
selectedModelId가 지원 모델인지, 사용자 권한상 사용 가능한지 확인하고 AI 응답 생성 옵션에 반영한다.

**출력**
modelOption(modelId, displayName, provider)

**DB 영향**
없음 또는 AIResponseJob 옵션 저장

**상태 변화**
모델 선택값 확정

**권한**
로그인 필요

**오류**
지원하지 않는 모델, 권한 없음, 모델 사용 불가

**우선순위**
하

**비고**
모델 버튼 표시와 드롭다운 선택 상태는 FE 책임

---

### BE-INPUT-007 · 음성 입력 처리 기준 정의

MVP에서는 음성 인식 기능을 제공하지 않으며, 음성 입력 버튼 및 관련 UI는 구현 범위에서 제외한다.

**도메인**
InputAssist

**관련 요구사항**
REQ-057

**관련 화면**
음성 입력 버튼

**입력**
없음

**처리**
서버 STT, 음성 파일 업로드, 음성 텍스트 변환 API를 제공하지 않는다. 추후 도입 시 별도 SpeechToText 모듈로 확장한다.

**출력**
없음

**DB 영향**
없음

**상태 변화**
없음

**권한**
없음

**오류**
없음

**우선순위**
MVP 제외

**비고**
팀 내 공유용 명시 항목. MVP 개발 범위 아님

---

### BE-INPUT-008 · 입력 보조 접근 권한 검증

사용자가 해당 채팅에서 첨부, 웹 검색 옵션, 모델 선택값을 사용할 수 있는지 공통으로 검증한다.

**도메인**
InputAssistAuth

**관련 요구사항**
REQ-052, REQ-053, REQ-054, REQ-055, REQ-056

**관련 화면**
입력 보조 관련 실행 기능

**입력**
userId, chatId, branchId 선택값

**처리**
Chat ownerId와 요청 userId를 비교하고, 필요한 경우 Branch 소속 여부와 사용자 권한을 확인한다.

**출력**
hasAccess 또는 권한 오류

**DB 영향**
Chat 조회, Branch 조회 가능

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
CHAT_NOT_FOUND, BRANCH_NOT_FOUND, ACCESS_DENIED

**우선순위**
중

**비고**
공통 서비스 함수로 구현 권장
