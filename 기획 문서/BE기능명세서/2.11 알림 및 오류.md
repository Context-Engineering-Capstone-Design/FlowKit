## 2.11 알림 및 오류

**FE/BE 책임 기준**

### BE-NOTIFY-001 · 표준 오류 응답 반환

각 도메인에서 발생한 오류를 FE가 일관되게 처리할 수 있도록 표준 오류 응답 형식으로 반환한다.

도메인 | Error, Common
관련 요구사항 | REQ-064
관련 화면 | 오류 배너

입력 | errorType, requestContext, detail 선택값
처리 | 오류 유형을 분류하고 errorCode, message, detail, traceId를 포함한 표준 응답 객체를 생성한다.
출력 | errorCode, message, detail, traceId

DB 영향 | 없음
상태 변화 | 없음
권한 | 상황별
오류 | VALIDATION_ERROR, UNAUTHORIZED, ACCESS_DENIED, NOT_FOUND, INTERNAL_ERROR
우선순위 | 상

비고 | 오류 배너 표시 여부와 닫기 버튼은 FE 책임

### BE-NOTIFY-002 · 도메인별 오류 코드 매핑

인증, 채팅, 브랜치, 메시지 블록, 정제, Context 적용, AI 응답 등 도메인별 오류를 공통 오류 코드 체계로 매핑한다.

도메인 | Error, Common
관련 요구사항 | REQ-064
관련 화면 | 오류 배너, 모달 오류 메시지

입력 | domainName, domainErrorType
처리 | 도메인별 내부 오류를 FE 노출용 errorCode와 사용자 메시지로 변환한다.
출력 | mappedError(errorCode, message, severity)

DB 영향 | 없음
상태 변화 | 없음
권한 | 상황별
오류 | 매핑되지 않은 오류, 알 수 없는 도메인 오류
우선순위 | 중

비고 | 사용자에게 보여줄 문구와 개발자용 detail을 분리

### BE-NOTIFY-003 · 주요 작업 결과 응답 메타데이터 반환

저장, 수정, 승인, 거절, 적용, 삭제 등 주요 작업 성공 결과를 FE가 토스트로 표시할 수 있도록 응답 메타데이터를 반환한다.

도메인 | Notification, Common
관련 요구사항 | REQ-065
관련 화면 | 토스트 알림

입력 | actionType, resultStatus
처리 | 작업 결과에 따라 successCode, message, affectedResourceId를 응답에 포함한다.
출력 | successCode, message, affectedResourceId

DB 영향 | 없음
상태 변화 | 없음
권한 | 상황별
오류 | 작업 실패, 부분 실패
우선순위 | 하

비고 | 토스트 표시, 노출 시간, 위치, 애니메이션은 FE 책임

### BE-NOTIFY-004 · 부분 실패 응답 처리

전체 승인, 전체 거절, 다중 첨부 처리처럼 여러 항목을 처리하는 작업에서 일부만 실패한 결과를 반환한다.

도메인 | Error, Common
관련 요구사항 | REQ-064, REQ-065
관련 화면 | 오류 배너, 토스트 알림

입력 | actionType, successItems, failedItems
처리 | 성공 항목과 실패 항목을 분리하고, 실패 사유를 항목별로 구성해 반환한다.
출력 | partialResult(successItems, failedItems, message)

DB 영향 | 없음
상태 변화 | 일부 항목만 처리 완료
권한 | 로그인 필요 또는 상황별
오류 | PARTIAL_FAILURE, ITEM_NOT_FOUND, ITEM_ACCESS_DENIED
우선순위 | 중

비고 | FE는 결과에 따라 토스트 또는 배너 중 적절한 표시 방식을 선택

### BE-NOTIFY-005 · 서버 오류 로그 기록

서버 내부 오류나 AI Provider 오류가 발생했을 때 추적 가능한 오류 로그를 저장한다.

도메인 | ErrorLog
관련 요구사항 | REQ-064
관련 화면 | 오류 배너

입력 | traceId, userId 선택값, requestPath, errorCode, errorDetail
처리 | 오류 발생 시 traceId를 생성하고 요청 경로, 사용자 식별자, 오류 코드, 상세 로그를 저장한다.
출력 | traceId

DB 영향 | ErrorLog 생성
상태 변화 | 없음
권한 | 상황별
오류 | 로그 저장 실패
우선순위 | 중

비고 | FE에는 traceId만 제공하고 내부 stack trace는 노출하지 않음

### BE-NOTIFY-006 · 클라이언트 오류 로그 수집

FE에서 발생한 주요 오류를 서버에 기록해 추후 디버깅할 수 있도록 한다.

도메인 | ErrorLog
관련 요구사항 | REQ-064
관련 화면 | 오류 배너, 토스트 알림

입력 | userId 선택값, clientErrorType, message, pageContext, userAgent
처리 | 클라이언트 오류 로그 형식을 검증하고 ErrorLog 또는 ClientErrorLog로 저장한다.
출력 | logId, receivedAt

DB 영향 | ClientErrorLog 생성
상태 변화 | 없음
권한 | 로그인 필요 또는 선택적 인증
오류 | 로그 형식 오류, 저장 실패
우선순위 | 하

비고 | MVP 제외 가능. 화면 표시 자체와 무관한 운영 보조 기능
