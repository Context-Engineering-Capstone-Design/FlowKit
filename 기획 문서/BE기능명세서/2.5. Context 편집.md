## 2.5 Context 편집

**FE/BE 책임 기준**

### BE-CTXEDIT-001 · Context 편집 패널 상태 처리 기준 정의

Context 편집 패널의 열림/닫힘 상태가 FE 화면 상태로 처리됨을 정의한다.

도메인 | ContextEdit
관련 요구사항 | REQ-022
관련 화면 | Context 패널 버튼, 닫기 버튼

입력 | 없음
처리 | 패널 표시 여부는 FE 로컬 상태로 처리하며, BE에는 별도 저장하지 않는다.
출력 | 없음

DB 영향 | 없음
상태 변화 | 패널 열림/닫힘 상태 변경은 FE에서만 발생
권한 | 없음
오류 | 없음
우선순위 | 하

비고 | BE API 불필요. 문서상 책임 경계 명시용

### BE-CTXEDIT-002 · 자연어 편집 지시 검증

블록별 정제 실행 시 전달된 자연어 편집 지시가 유효한지 검증한다.

도메인 | ContextEdit
관련 요구사항 | REQ-025
관련 화면 | 블록별로 정제하기 버튼, AI 편집 지시 입력창

입력 | userId, instructionText
처리 | instructionText의 빈값, 길이 제한, 금지 문자열, 지원 가능한 입력 형식을 검증한다.
출력 | validationResult, normalizedInstruction

DB 영향 | 없음
상태 변화 | 편집 지시 입력값 확정
권한 | 로그인 필요
오류 | 지시문 없음, 지시문 길이 초과, 지원하지 않는 형식
우선순위 | 상

비고 | 편집 지시 저장·세션 생성 없음. 실행 시점 스냅샷 구성은 BE-REFINE-001 책임

### BE-CTXEDIT-003 · Context 편집 접근 권한 검증

사용자가 해당 채팅·브랜치의 Context 편집 작업에 접근할 수 있는지 공통으로 검증한다.

도메인 | ContextEditAuth
관련 요구사항 | REQ-023, REQ-025
관련 화면 | Context 편집 관련 전체 기능

입력 | userId, chatId, branchId
처리 | Chat ownerId와 요청 userId를 비교하고, branchId가 해당 Chat에 속하는지 검증한다.
출력 | hasAccess 또는 권한 오류

DB 영향 | Chat 조회, Branch 조회
상태 변화 | 없음
권한 | 로그인 필요, 채팅 소유자
오류 | CHAT_NOT_FOUND, BRANCH_NOT_FOUND, ACCESS_DENIED
우선순위 | 상

비고 | 공통 서비스 함수로 구현 권장
