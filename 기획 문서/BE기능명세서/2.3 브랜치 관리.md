## 2.3 브랜치 관리

### BE-BRANCH-001 · 브랜치 목록 조회

현재 채팅에 생성된 Main 브랜치와 하위 브랜치 목록을 조회한다.

**도메인**
Branch

**관련 요구사항**
REQ-007

**관련 화면**
좌측 사이드바 브랜치 목록

**입력**
userId, chatId

**처리**
채팅 접근 권한을 확인한 뒤 해당 Chat에 속한 Branch를 생성순으로 조회한다.

**출력**
branchList(branchId, branchName, branchType, parentBranchId, isActive)

**DB 영향**
Branch 조회, Chat 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
채팅 없음, 권한 없음, 브랜치 없음

**우선순위**
상

**비고**
정렬: branchType=MAIN 우선 후 createdAt ASC

---

### BE-BRANCH-002 · 브랜치 전환 조회

사용자가 선택한 브랜치로 이동할 수 있도록 메시지 목록, 출발 Context 정보, 원본 위치 매핑을 함께 조회한다.

**도메인**
Branch, MessageBlock, Context

**관련 요구사항**
REQ-008, REQ-011, REQ-012, REQ-013

**관련 화면**
브랜치 항목 클릭, Context pill 클릭, 중앙 채팅 영역

**입력**
userId, chatId, branchId

**처리**
채팅·브랜치 접근 권한을 확인하고 MessageBlock 목록과 BranchSourceContext를 조회한다. sourceContextInfo에는 pill 클릭 시 스크롤에 필요한 sourceMessageBlockId, sourceBranchId, scrollTargetIndex를 포함한다.

**출력**
branchMeta, messageBlocks, sourceContextInfo(contextBlockId, previewText, sourceMessageBlockId, sourceBranchId, scrollTargetIndex)

**DB 영향**
Branch 조회, MessageBlock 조회, BranchSourceContext 조회

**상태 변화**
현재 표시 브랜치 변경

**권한**
로그인 필요, 채팅 소유자

**오류**
채팅 없음, 브랜치 없음, 권한 없음

**우선순위**
상

**비고**
BE-MSG-002 조회 로직 내부 재사용 가능. 전송 전 Context pill 표시·선택은 FE 상태. sourceContextInfo는 브랜치 출발 Context 참조용

---

### BE-BRANCH-003 · 브랜치 생성 입력값 검증

브랜치 생성 요청에 필요한 브랜치 이름, 기준 브랜치, 분기 지점, 포함 Context가 유효한지 검증한다.

**도메인**
Branch, Context

**관련 요구사항**
REQ-009, REQ-010

**관련 화면**
브랜치 생성 모달, 이 Context로 브랜치 생성 버튼

**입력**
userId, chatId, baseBranchId, branchName, baseMessageBlockId, contextBlockIds

**처리**
채팅 소유권, 기준 브랜치 소속, 분기 지점 메시지 존재 여부, Context 블록 소속 여부를 검증한다.

**출력**
validationResult

**DB 영향**
Chat 조회, Branch 조회, MessageBlock 조회, Context 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
브랜치 이름 없음, 기준 브랜치 없음, 메시지 블록 없음, Context 블록 없음, 권한 없음

**우선순위**
상

**비고**
브랜치 생성 API 내부 검증으로 구현 권장

---

### BE-BRANCH-004 · 선택 Context 기반 브랜치 생성

선택한 메시지 블록 또는 적용 Context를 기반으로 새 브랜치를 생성한다.

**도메인**
Branch, Context

**관련 요구사항**
REQ-010

**관련 화면**
이 Context로 브랜치 생성 버튼

**입력**
userId, chatId, baseBranchId, branchName, baseMessageBlockId, contextBlockIds

**처리**
입력값 검증 후 새 Branch를 생성하고, 기준 브랜치, 분기 지점, 출발 Context 참조 정보를 연결한다.

**출력**
branchId, branchName, branchType, parentBranchId, sourceContextRefId

**DB 영향**
Branch 생성, BranchSourceContext 생성

**상태 변화**
기존 채팅 → 새 브랜치 추가

**권한**
로그인 필요, 채팅 소유자

**오류**
브랜치 생성 실패, Context 연결 실패, 중복 브랜치명

**우선순위**
상

**비고**
MVP 포함

---

### BE-BRANCH-005 · 브랜치 출발 Context 참조 저장

새 브랜치가 어떤 Context를 기반으로 생성되었는지 추적할 수 있도록 출발 Context 참조를 저장한다.

**도메인**
Branch, Context

**관련 요구사항**
REQ-010, REQ-011

**관련 화면**
브랜치 생성, 브랜치 상단 Context 정보

**입력**
branchId, contextBlockIds, baseMessageBlockId

**처리**
선택된 Context 블록 ID, 원본 메시지 블록 ID, 기준 브랜치 ID를 BranchSourceContext로 저장한다.

**출력**
sourceContextRefId, contextBlockRefs

**DB 영향**
BranchSourceContext 생성

**상태 변화**
브랜치에 출발 Context 참조 연결

**권한**
로그인 필요, 채팅 소유자

**오류**
Context 없음, 원본 블록 없음, 저장 실패

**우선순위**
상

**비고**
AI 요약 생성이 아니라 원본 Context 참조 저장이 목적

---

### BE-BRANCH-006 · 브랜치 접근 권한 검증

사용자가 특정 브랜치에 접근할 수 있는지 공통으로 검증한다.

**도메인**
BranchAuth

**관련 요구사항**
REQ-007, REQ-008, REQ-010, REQ-011, REQ-012

**관련 화면**
브랜치 관련 전체 기능

**입력**
userId, chatId, branchId

**처리**
Branch가 해당 Chat에 속하는지 확인하고, Chat ownerId와 요청 userId를 비교한다.

**출력**
hasAccess 또는 권한 오류

**DB 영향**
Chat 조회, Branch 조회

**상태 변화**
없음

**권한**
로그인 필요, 채팅 소유자

**오류**
BRANCH_NOT_FOUND, CHAT_ACCESS_DENIED

**우선순위**
상

**비고**
공통 서비스 함수로 구현 권장
> 2026-08-20 변경: 새 일반 브랜치 생성 요청은 `contextBlockIds`를 빈 목록으로 보낸다. 선택 Context 검증·저장은 기존 기록 호환을 위해 유지하되 화면 기능으로는 제공하지 않는다.
