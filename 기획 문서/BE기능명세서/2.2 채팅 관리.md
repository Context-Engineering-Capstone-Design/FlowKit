## 2.2 채팅 관리

### BE-CHAT-001 · 새 채팅 생성

사용자가 새로운 대화를 시작할 수 있도록 빈 채팅을 생성한다.

**도메인**
Chat

**관련 요구사항**
REQ-004

**관련 화면**
새 채팅 버튼

**입력**
userId

**처리**
사용자 소유의 신규 Chat 레코드를 생성하고 기본 제목과 초기 상태를 설정한다.

**출력**
chatId, title, createdAt

**DB 영향**
Chat 생성

**상태 변화**
없음 → 새 채팅 생성

**권한**
로그인 필요

**오류**
사용자 없음, 채팅 생성 실패

**우선순위**
상

**비고**
MVP 포함

---

### BE-CHAT-002 · 기본 Main 브랜치 생성 및 초기 상태 반환

새 채팅 생성 시 Main 브랜치를 함께 생성하고, FE가 초기 화면을 바로 구성할 수 있도록 빈 상태를 반환한다.

**도메인**
Chat, Branch

**관련 요구사항**
REQ-004, REQ-007

**관련 화면**
새 채팅 버튼, 중앙 채팅 영역, 브랜치 목록

**입력**
chatId, userId

**처리**
Chat에 Main Branch를 생성한 뒤 chatMeta, branchMeta, 빈 messageBlocks, branchList를 함께 반환한다.

**출력**
chatMeta, branchMeta, mainBranchId, branchName, messageBlocks: [], branchList

**DB 영향**
Chat 생성, Branch 생성

**상태 변화**
새 채팅 → Main 브랜치 보유, 초기 화면 구성 가능

**권한**
로그인 필요, 채팅 소유자

**오류**
chatId 없음, Main 브랜치 생성 실패

**우선순위**
상

**비고**
BE-CHAT-001과 트랜잭션 처리 권장. 전송 전 Context pill 상태는 FE 로컬 상태

---

### BE-CHAT-003 · 최근 대화 목록 조회

사용자가 최근 생성·수정한 대화 목록을 조회한다.

**도메인**
Chat

**관련 요구사항**
REQ-005

**관련 화면**
좌측 사이드바 최근 대화

**입력**
userId, cursor, limit

**처리**
사용자 소유 Chat을 lastActivityAt 기준 내림차순으로 조회하고, UI에는 chatId와 title만 반환한다.

**출력**
chatList(chatId, title), nextCursor

**DB 영향**
Chat 조회

**상태 변화**
없음

**권한**
로그인 필요

**오류**
사용자 없음, 조회 실패

**우선순위**
상

**비고**
정렬용 lastActivityAt은 DB 내부 필드, API 응답에 미포함

---

### BE-CHAT-004 · 채팅 제목 생성 결과 반영

첫 사용자 프롬프트를 기반으로 생성된 채팅 제목을 최근 대화 목록에 표시할 수 있도록 저장한다.

**도메인**
Chat, AI

**관련 요구사항**
REQ-005, REQ-006

**관련 화면**
최근 대화 목록

**입력**
chatId, generatedTitle, sourceMessageBlockId

**처리**
채팅 소유권을 확인하고, AI 모델링 파트가 생성한 제목의 길이·빈값·금칙 문자 여부를 검증한 뒤 Chat.title에 저장한다.

**출력**
title

**DB 영향**
Chat 수정

**상태 변화**
기본 제목 → 생성된 제목

**권한**
로그인 필요, 채팅 소유자

**오류**
생성 제목 없음, 제목 형식 오류, 채팅 없음, 권한 없음

**우선순위**
상

**비고**
제목 생성 로직은 AI 모델링 파트 책임이며, BE는 제목 저장·검증·조회 책임

---

### BE-CHAT-005 · 채팅 상세 조회

사용자가 최근 대화 항목을 클릭했을 때 해당 채팅의 현재 브랜치와 메시지 목록을 조회한다.

**도메인**
Chat, Branch, MessageBlock

**관련 요구사항**
REQ-005, REQ-013

**관련 화면**
최근 대화 클릭, 중앙 채팅 영역

**입력**
chatId, branchId 선택값

**처리**
채팅 소유권 확인 후 요청 branchId 또는 기본 Main 브랜치의 메시지 블록을 순서대로 조회한다.

**출력**
chatMeta, branchMeta, messageBlocks, branchList

**DB 영향**
Chat 조회, Branch 조회, MessageBlock 조회

**상태 변화**
현재 표시 채팅 변경

**권한**
로그인 필요, 채팅 소유자

**오류**
채팅 없음, 브랜치 없음, 권한 없음

**우선순위**
상

**비고**
BE-MSG-002 조회 로직 내부 재사용 가능. 전송 전 Context pill은 FE 상태. 전송 후 적용 이력은 AppliedContextLog

---

### BE-CHAT-008 · 채팅 접근 권한 검증

사용자가 특정 채팅에 접근할 권한이 있는지 공통으로 검증한다.

**도메인**
ChatAuth

**관련 요구사항**
REQ-004, REQ-005, REQ-006

**관련 화면**
채팅 관련 전체 기능

**입력**
userId, chatId

**처리**
Chat의 ownerId와 요청 userId를 비교하여 접근 가능 여부를 판단한다.

**출력**
hasAccess 또는 권한 오류

**DB 영향**
Chat 조회

**상태 변화**
없음

**권한**
로그인 필요

**오류**
CHAT_NOT_FOUND, CHAT_ACCESS_DENIED

**우선순위**
상

**비고**
공통 서비스 함수로 구현 권장

### BE-CHAT-009 · 채팅 삭제

사용자가 자신의 대화를 완전히 삭제할 수 있도록 처리한다.

**도메인**
Chat

**관련 요구사항**
REQ-066

**관련 화면**
사이드바 최근 대화 항목 삭제 버튼

**입력**
userId, chatId

**처리**
채팅 소유권을 확인한 뒤 Chat과 그에 속한 브랜치, 메시지, 첨부 파일을 함께 삭제한다. 첨부 원본 파일도 저장소에서 제거한다. 휴지통이나 복구는 제공하지 않는다.

**출력**
deleteSuccess, actionMeta

**DB 영향**
Chat 삭제, 하위 브랜치·메시지·첨부 삭제

**상태 변화**
채팅 존재 → 삭제됨

**권한**
로그인 필요, 채팅 소유자

**오류**
채팅 없음, 권한 없음, 삭제 실패

**우선순위**
중

**비고**
목록에서 숨기기만 하지 않고 실제로 삭제한다. 화면의 확인 창과 새 빈 대화 전환은 FE 책임
